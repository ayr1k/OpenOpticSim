# 验证与范围

框架继承 OpenOpticSim 的解析、瞳瞄准、像差、衍射、优化、机械及变焦回归测试。运行 `cargo test --workspace --locked --release`。

新增三维测试覆盖：零位姿与原追迹交点/光程一致、刚体旋转平移协变、倾斜平面解析交点及 Snell 定律、圆/椭圆/矩形/环形遮挡、取消和零方向拒绝、单/多线程相同顺序和数值。它们是声明能力范围的验证，不能证明任意病态曲面都能求交。

求交保留原球面/圆锥/偶次非球面的有界 Newton 方法。掠入射、曲面域外、迭代不收敛明确终止，不把它们计为零误差。三维尚未增加自动碰撞认证、真实瞳瞄准或非顺序路径。

原有 PSF/MTF 为有适用范围的标量模型；SphereKirchhoff 用于已有同轴处方离轴视场，不表示支持偏心系统。详见同目录下随框架分发的 DIFFRACTION.md、COORDINATES.md（若有）及 API.md。性能报告给出实际采样、二进制哈希、重复测量数据和数值差异，不通过降低精度换取加速。

发布的 Windows x64 库和 CLI 经本地验证；独立 CI 配置可验证其他平台的源码构建，但不能把尚未执行的远程 CI 当作已通过。实际本地证据随 SDK/source 附件保存。安装或软件集成还需验证宿主的线程生命周期、取消与文件权限。
