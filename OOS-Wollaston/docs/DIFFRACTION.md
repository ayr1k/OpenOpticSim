# 快速 PSF / MTF 与成像的计算约定

本文记录保留兼容的快速模型。0.9 新增的直接离轴 Kirchhoff、光线管振幅、平面像面与覆盖检查见 [COVERAGE.md](COVERAGE.md)；其物方角度和振幅假设与本文不同，不能混用模型条件。

## 已验证的功能范围

0.2.0 将旧版实验性计算替换为**带适用性与采样收敛检查的标量参考球面模型**。支持旋转对称、空气像方、有限/无限物距、球面/非球面、真实口径裁剪和多波长非相干叠加。它不是矢量电磁或辐射度模型。数值结果的准确性与模型近似的物理适用性是两件不同的事。

使用入口：“PSF / MTF”选择视场、单色或项目光谱及采样上限，先自动对焦并采纳候选，再计算。结果可导出带处方、光谱和误差的 MTF CSV 报告。“成像预览”按各视场分别计算，失败视场显示原因，成功视场仍可查看。

## 波前、坐标与尺度

1. 精确追迹主光线，像面交点为参考球中心 C。主光线与近轴出瞳平面的交点为 E，球半径 R=|C-E|。空气中允许把最后一面出射直线向后延长到虚出瞳；只计算其几何外推光程。
2. 在光阑边缘发射 256 条精确瞄准光线，映射到参考球，构造投影瞳边界。边界非凸/折叠、主光线失败或球面未命中时拒绝。这个边界多边形与二值口径光栅会留下离散误差。
3. 在球面 XY 投影上放置规则网格。用二维 Newton 反解入射位置，使出射光线在参考球上的 XY 坐标命中网格（残差 <1e-9 mm）。不再把均匀光阑坐标误当成均匀出瞳坐标。求解过程中检测局部 Jacobian 翻转和退化；无法证明任意复杂系统的全局映射唯一性。
4. 反解时忽略口径，完成后用每个表面的实际交点逐一裁剪。被物理口径遮挡的网格为零振幅；求交失败、全反射、数值失败直接报错，不能伪装成黑色瞳点。
5. 入射相位以发射平面上的轴点为零点：无限远为起点横向坐标与入射方向的点积；有限物距为到物点的距离差，用有理化公式计算，避免超远物距下两个巨大光程相减损失精度。累计各介质光程，去掉最后一面到像面的路程，换成最后一面到参考球的有符号路程。减去主光线参考光程得到 OPD。
6. 复瞳采用 exp(+i 2π OPD/λ)，RustFFT 使用负指数变换。RMS 仅移除活塞，保留离焦、倾斜与其他像差。相位斜坡测试验证图像位移的正负方向。
7. 振幅假设是**参考球面投影上均匀**；没有根据光线密度计算照度，也没有镀膜、Fresnel 透射、斜因子、偏振或高 NA 矢量修正。
8. 图像间距 Δx=λR/(N Δp)，单位 mm。频率间距 Δf=1/(N Δx)，单位 lp/mm。PSF 是单位总和的像素能量，MTF=|FFT(PSF)|/OTF(0)，弧矢对应 X、子午对应 Y，包含 Nyquist 端点。

参考球面方法遵循光程差与参考球的常规定义；独立对照使用 [RayOptics 的公开追迹与波前约定](https://ray-optics.readthedocs.io/en/latest/_modules/rayoptics/raytr/waveabr.html)。具体实现和符号以本文及公开测试为准，不声称与商业软件的未指定默认设置等同。

## 多色处理

所有波长直接落在同一物理像面网格：每个波长调整自己的瞳网格间距，使 Δx 相同，不对低分辨率 PSF 做插值。参考像点选取最接近 d 线的配置波长主光线。其他波长相对参考像点的偏移通过复瞳相位斜坡保留；不会把每个颜色的质心各自移回零点。

按项目权重相加强度后，再求复 OTF 的模。**不能平均单色 MTF**，否则会抹掉横向色差造成的相位抵消。各波长独立归一化，权重是用户指定的相对探测功率，不含系统透射和传感器光谱响应。权重先缩放再归一化，避免大数溢出。

## 每次计算的验收门槛

FFT 零填充倍率为 4；有效瞳宽按 64 → 128 → 256 逐级加密，图像物理像素间距保持不变、计算视窗扩大。用户可将上限设为 128。每次至少比较两级：

| 检查 | 门槛 |
|---|---|
| 共同物理频率上的两条 MTF 最大绝对变化 | ≤0.015 |
| PSF 重叠区域 L1 差 + 新视窗外侧能量 | ≤0.04 |
| 相邻有效瞳点的未包裹相位差（含色差位移） | ≤0.25 波 |
| 计算图像最外侧 10% 边带能量 | ≤0.005 |
| 99% 能量半径内的局部傅里叶展开估计误差 | ≤0.05 波 |

局部传播误差估计保守使用 s_max² r²/(2Rλ)+r³/(2R²λ)，r 包含该波长主光线相对共同参考点的位移。它用于筛查局部傅里叶展开，不是对偏振、幅度假设或整个光学模型的总误差上界。边带检查降低 FFT 周期混叠风险，不能证明整个无限图像域的截断误差。

额外限制：场角绝对值≤0.15 rad；参考球面边界的出射方向横向正弦≤0.25；像方严格 n=1；像面位于近轴出瞳之后。退化或过远的参考球在双精度舍入估计 32·ε·R 超过 1e-5 波时拒绝。边界采样和局部 Jacobian 检查不是任意病态光学系统的可逆性证明。未通过就返回具体数值和调整建议，不展示一张貌似有效的图。

这些门槛定义当前产品的数值质量级别。它们不是任意镜头 MTF 绝对误差≤0.015 的保证；独立对照容差另见报告。

## 局部平面成像

- 每个视场使用经过收敛检查的完整多色 PSF，图案和 PSF 在同一个物理网格计算。
- 网格、点阵和正弦分辨率条纹都是周期延拓的局部平面目标，边界条件明确为周期；不把周期边界称为真实传感器边缘。
- 正弦条纹分三区，横向周期数为 8/16/32。对应空间频率是周期数除以该块标示宽度（mm）。不是相机分辨率认证图卡。
- 源图在原生计算像素内 4×4 面积采样。卷积使用完整的复 OTF，包括不对称 PSF 的相位。不截取 41×41 核、不丢弃光晕、不把剩余能量重新放大。
- 卷积后面积平均显示为 256×256；源图同样处理。显示线性灰度，图像采样不是 Bayer、像素孔径或相机 gamma 模型。
- 每块以参考主光线像点为中心；畸变位移另行报告，不用平移局部图案冒充整幅几何畸变。各块物理宽度可能不同，UI 显示标尺，不能仅比较屏幕上的模糊大小。
- 当前为各视场局部平移不变近似。尚未实现整幅传感器的空间变化卷积和畸变重映射，也未验证每一块内部 PSF 的场变化；不是整幅照片或三维景深模拟。

## 独立证据与重现

运行：

    cargo test -p openoptics --release --locked
    cargo build -p oos-cli --release --locked
    .tools/validation/Scripts/python scripts/validate_diffraction.py

[机器可读报告](validation-diffraction.json)包含五组算例：缩光阑单透镜、离轴多色双胶合、有限物距离轴非球面、1e12 mm 超远有限物距、裁剪瞳单透镜。

0.7 另加入 400 mm 修正版三个多色视场：[八算例报告](validation-diffraction-0.7.json)。运行 `python scripts/validate_diffraction.py --extra-project examples/400mm-repaired.oos.json --output docs/validation-diffraction-0.7.json` 可重现。修正版局部成像输出另与 NumPy 卷积逐像素比较，8 位图像最大差为零；这不扩大上述物理模型适用范围。

RayOptics 独立求交/折射重追全部导出的有效入射位置，并独立计算参考球和光程；有限物距入射相位用 Python Decimal 的 50 位距离相减验证稳定公式；检查反解网格位置。NumPy 从独立 OPD 重建 PSF 与复 OTF。另用直接球面距离积分抽查主峰附近的强度，以检验局部傅里叶近似。验证共用 OSS 给出的发射坐标与孔径掩码，因此不是对所有可能瞳拓扑或全部振幅模型的独立认证。

解析圆孔使用 Bessel J1 Airy 公式和解析 MTF；Rust 回归还检查相位斜坡方向、平移 MTF 不变性、多色 OTF 相消、权重缩放、有限物距非球面、裁剪瞳、失败隔离、取消，以及卷积的常数保持、冲激方向、能量与正弦对比度传递。测试图与独立 NumPy 实现逐像素比较。

诊断 API "pupil" / "pupils" 导出原始 OPD、采样起点、球面位置、权重与物理间距，便于复算。诊断数据本身没有通过收敛的承诺，不用于替代生产 "wave" 操作。
