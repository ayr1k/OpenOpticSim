# OpenOpticSim 1.5.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

构建与本地验证日期：2026-10-20。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.5.0/OpenOpticSim_1.5.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.5.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

打开示例 → 编辑整枚镜片、材料、机械边缘与镜组 → 检查通光和传感器覆盖 → 对焦、扫描与分析画质 → 在统一条件下比较版本 → 检查并采纳优化候选 → 保存项目与导出 PDF 名义技术图纸。

1.5 重点改善自动生成和自动优化中焦距、F 数及最小厚度约束容易失败的问题，并加入结构探索、镜片级玻璃选择和可保存搜索断点。完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/CHANGELOG.md)。

- 约束恢复参与试步：按真实近轴入瞳校正 F 数，使用曲率恢复有效焦距，修复实体厚度和跨光阑间隙；不修改锁定变量或超出已设边界。
- 硬约束优先，保留完整验收通过的候选；阶段失败时有限插入中间孔径/视场重试，失败光线不作零误差评分。
- 可选扩展结构：移动光阑、后置校正片和前置负透镜，每个变体最多增加一片。Tessar、Planar、双高斯、Sonnar 原始起点保留。
- 镜片级玻璃选择：逐片尝试目录替代材料并重新优化，不连带改变其他共享同种玻璃的镜片。
- 搜索预算、显式最小厚度和可保存断点；重开后继续已完成尝试，恢复时重新验收保留候选。
- 保留既有变焦/对焦/光圈扫描、多配置优化、传感器覆盖、镀膜、PSF/MTF、测试图、版本对比、PDF 技术图纸与 25 章离线手册。

固定的 12 项设计任务中，通过数从 **4/12 提高到 9/12**。通过方案均以 49×49 采样和独立 RayOptics 追迹追加复核。两版均设置每阶段 25 次迭代、一个起点、固定玻璃和原拓扑；新版额外执行约束恢复及有限重试，并采用显式 0.5/0.1 mm 厚度下限。这不是等耗时比较，也不是任意指标的成功概率；仍有 3 项全画幅任务未通过。详见 [基准证据](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/validation-benchmark-1.5.json)。

## 新功能从哪里开始

打开「设计 → 从指标创建设计」，先加载 50 mm F8 / 6×4 mm 入门任务，再选择结构探索、逐片材料搜索和尝试预算。搜索中点击「暂停并保留断点」，然后保存 `.oos.json`；重开后点击「从断点继续」。未完成的单次尝试会重跑；任务更改会使旧断点失效。

手工优化的变量编辑器新增恢复说明。焦距需要可调曲率，F 数需要光阑半径，间隙需要对应厚度；软件不会为了通过约束擅自解锁变量。只有全部检查通过才允许采用。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，具体最低系统兼容尚未完成独立矩阵验收。
- 下载资产：`OpenOpticSim_1.5.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者，运行软件请选择 `.exe` 安装包。
- 安装包包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名。干净、无 WebView2 的 Windows 断网安装尚待实际验收，不将“构建成功”描述为该测试已通过。
- 项目文件保留在用户选择的位置。升级前建议备份自己的 `.oos.json`；不要将未保存的内存状态作为唯一副本。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.5.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.5.0_x64-setup.exe.sha256
```

正式下载附件的哈希以该 Release 的 `SHA256SUMS.txt` 和 `manifest.json` 为准。校验值用于检查文件一致性，不替代发布者签名。源码内较早的本地准备记录仅作为历史证据，不作为新下载文件的校验依据。

打开软件后按 F1 查看帮助，Ctrl+K 搜索功能；推荐从“单透镜”或“双胶合探索”开始，再阅读 [新手教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/manual/start.md)。

## 适用范围与已知限制

- 可见光、旋转对称、顺序折射、有限 / 无限物距、平面传感器；具体范围以 [STATUS](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/STATUS.md) 和 [COVERAGE](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/COVERAGE.md) 为准。
- PSF / MTF 使用限定范围的标量模型，需关注收敛与适用性；瞳求解失败不等于物理遮挡。
- 成像预览为局部平面目标，不是完整三维摄影场景或整幅空间变化渲染。
- PDF 图纸是名义设计记录，未指定的公差、表面质量、镀膜和装配要求不会自动生成。
- 400 mm 示例为用户自建模型的教学修正，约 f/16，不是佳能官方处方或 400 mm f/2.8 复刻。
- 结构探索仍有界，逐片玻璃搜索不同时穷举多枚材料；几何通过不等于 MTF、公差或制造通过。搜索断点只保留最佳 8 个候选和全部尝试摘要。
- 原生文件对话框 / 快捷键的完整人工验收，以及干净 Windows 离线安装仍待补齐。
- 本地验证不替代远程 CI 或全新 Windows 环境验证；线上状态由维护者在 [Actions](https://github.com/ayr1k/OpenOpticSim/actions) 确认。

## 验证与反馈

本轮前端 74 项、Rust / 桌面 100 项测试及生产构建通过；四个经典结构、24–70mm 和 400mm 旧处方 RMS 保持一致，400 mm 保存回归的 38,508 条采样与既有基准一致。变焦 13 个扫描点与 7 个补偿点、独立衍射 8 个算例通过。生产页面验证了搜索、保存重开与候选重新验收。检查二进制个人路径、程序启动与打包资源一致性；没有将这些检查描述为完成全新 Windows 安装或升级验收。

具体证据见 [1.5 发布验收](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/validation-release-1.5.json)、[设计与断点回归](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/docs/validation-design-1.5.json)。下载附件以 `manifest.json` / `build-report.json` 为准。问题请提交到 [Issues](https://github.com/ayr1k/OpenOpticSim/issues)，注明版本、最小处方、目标、变量边界、复现步骤与错误提示，并删除私人信息。安全问题按 [SECURITY.md](https://github.com/ayr1k/OpenOpticSim/blob/v1.5.0/SECURITY.md) 处理。
