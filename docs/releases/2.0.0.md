# OpenOpticSim 2.0.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0。本版将完整计算核心独立为 **OOS-Wollaston v1（1.0.0）**，桌面程序和嵌入接口共用同一份 Rust 双精度实现。

构建与本地验证日期：2026-10-21。实际发布日期以 GitHub Release 为准。下面的下载链接在维护者发布标签及附件后生效。

## 用户可以完成什么

继续使用原有的设计生成、约束优化、变焦/对焦/光圈扫描、玻璃与镀膜分析、点列图、PSF/MTF、测试图成像、版本对比、保存重开和 PDF 技术图纸。同时可以在 **设计 → 三维追迹与调试** 中设置表面、镜组和传感器的偏心/倾斜，发射斜光线，查看三维路径与逐面诊断。

- **独立框架：**仓库 `OOS-Wollaston/` 自带 Cargo 工作区、模型和玻璃数据、示例、测试、许可、文档及 CI，可整体复制到新仓库。
- **性能：**复用同一波长下的顶点、折射率、发射平面，减少瞳瞄准和波前反向采样的重复准备。固定本机测试中，六个示例的几何分析约为 v1.5 的 1.10–1.46 倍速度；所测 PSF/预览约 1.07–1.19 倍。相同请求与采样，比较输出的最大数值差异为 0；不代表所有任务或硬件都达到该速度。
- **三维顺序几何：**独立表面坐标、镜组刚体变换、倾斜传感器、全局及局部交点、实际法线与光程。框架支持附加圆/椭圆/矩形/环形口径和有序并行光束。
- **光线调试器：**三维线框、视角调整、逐面 n/n′、入射/折射角、失败面与真实终止点；项目保存实验配置，可导出复现请求和光线记录。
- **嵌入：**Rust 库、JSON CLI、C ABI 1 / Windows DLL、Python ctypes 包装器，含所有权、错误、取消及并发约定。
- **帮助：**26 章可搜索离线手册，另有独立框架 API、坐标约定、迁移与验证说明。

## 安装与开始

- Windows x64；安装包包含 WebView2 离线安装组件、手册、字体及许可。日常使用不需要 Node、Python 或 Rust。
- 下载 `OpenOpticSim_2.0.0_x64-setup.exe`。升级前备份自己的 `.oos.json`。原有 schema 1/2/3 项目继续读取，1.5 设计搜索断点格式保持兼容。
- 打开示例，按 F1 查看帮助，或 Ctrl+K 搜索“三维”。三维默认五条轴向测试光线，可在“发射光线与资源”编辑起点与方向。
- 普通用户不需要框架 SDK。嵌入开发者阅读 `OOS-Wollaston/README.md`，使用框架源代码或 Windows SDK 附件。
- 本版未签名。已经验证本地构建、运行与计算；干净 Windows 断网安装、完整升级和原生对话框端到端流程尚未独立验收。

## 适用范围与已知限制

- 三维位姿仅供三维实验及 `trace_spatial` 使用。原有画质、优化、版本比较和 PDF 分析原始同轴处方；不能把原有 MTF 当作偏心镜头的结果。API 会拒绝把 spatial_options 交给同轴分析操作。
- 三维入口使用显式发射光线，尚无偏心系统的自动瞳瞄准、PSF/MTF、全局实体碰撞认证。镜组旋转绕组首名义顶点；重叠镜组拒绝计算。
- 顺序追迹遇全反射即终止，未增加非顺序路径、鬼影、GPU 或真实三维摄影场景渲染。曲面域外和求交不收敛会明确失败。
- 既有标量衍射、通光率、名义图纸与教学示例的范围不变。400 mm 仍为约 f/16 的教学修正版，不是佳能 400 mm f/2.8 官方处方。
- 性能报告包含进程启动和 JSON 输出开销；提供原始重复测量数据，不作为全硬件性能保证。

## 验证与反馈

验证包括既有 Rust/桌面回归与前端测试、六个经典/变焦/长焦处方的 v1.5 同条件比较、24–70 mm 扫描与补偿、400 mm 对焦和保存记录复算、独立 RayOptics/NumPy 衍射参考、三维解析与刚体不变量、C/Python/CLI 一致性和取消。三维变换后的 Tessar 交点另经 RayOptics 独立核对。

可检查 `docs/benchmark-2.0.json`、`docs/validation-framework-2.0.json`、`docs/validation-study-2.0.json`、`docs/validation-diffraction-2.0.json` 以及附件中的最终构建记录。当前本地准备不创建标签、不上传、不代替远程 CI。请在 Issues 提供版本、最小处方、采样、模型类型和复现步骤；安全问题按 SECURITY.md 处理。
