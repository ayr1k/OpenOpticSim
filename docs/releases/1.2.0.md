# OpenOpticSim 1.2.0

保留原有条款。

## 适用范围与已知限制

- 可见光、旋转对称、顺序折射、有限 / 无限物距、平面传感器；具体范围见 [STATUS](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/STATUS.md) 与 [COVERAGE](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/COVERAGE.md)。
- 补偿轨迹和加密扫描验证有限离散位置，不证明连续齐焦，也不是制造用凸轮设计。位置插值不等于焦距线性变化；补偿求解不保证同时达到任意指定焦距。
- 联合优化使用有界坐标搜索，默认保护每个视场；严格保护可能找不到可采纳的改善，不承诺全局最优。不支持多组联合对焦、自动材料替换或全焦段衍射目标优化。
- 通光比例是几何采样统计，不是精确照度。传感器覆盖缺口独立显示面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

**本版重点：变焦补偿轨迹生成、全焦段扫描、多配置联合优化和对焦距离扫描。** 新增统一操作工作台，保留 1.0 / 1.1 的全部设计与分析入口。

构建与本地验证日期：2026-10-19。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.2.0/OpenOpticSim_1.2.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.2.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

打开变焦示例 → 设置变倍组与补偿组 → 生成离散补偿轨迹 → 扫描整段变焦位置 → 定位失焦、遮挡或机械间隙问题 → 联合优化多个配置 → 高采样复核后采纳 → 保存研究记录与导出位置表。

完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/CHANGELOG.md)。

- **变焦补偿轨迹：**保持传感器固定，按命名配置驱动变倍组，逐位置搜索一个补偿组；高采样复核后，可将最多 30 个位置转换为可编辑命名配置。
- **全焦段扫描：**显示 RMS、实际焦距、F 数、畸变、通光与空气间隙变化。失败位置保留诊断，可单独筛选；支持在失败或 RMS 快变区段有限加密，最多 101 个采样位置。
- **多配置联合优化：**支持共享曲率、厚度和指定配置的镜组位置。逐配置、逐视场检查画质退化，并检查行程、机械间隙、实体厚度及启用的焦距容差和传感器覆盖条件。
- **对焦距离扫描：**支持对数间隔有限物距与无限远，固定传感器求解一个对焦组，报告位移、画质及实际物方半视场。
- **操作工作台：**曲线与结果表联动，点击位置重新追迹；联合优化提供同尺度的优化前后点列图。支持进度、取消、完整记录保存、过期提示，以及 JSON / CSV 导出。
- **帮助与兼容：**新增第 22 章离线教程；旧项目继续读取，原有光学计算范围保持不变。修复补偿求解因初始位置几何冲突而直接退出的问题，每个试探位置仍执行完整检查。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，具体最低系统兼容尚未完成独立矩阵验收。
- 下载资产：`OpenOpticSim_1.2.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者，运行软件请选择 `.exe` 安装包。
- 安装包包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名。干净 Windows 环境中的离线完整安装与升级尚待实际验收。
- 升级前建议备份 `.oos.json`。新增工作台记录请使用 1.2.0 编辑和保存，不依赖旧版保留新字段。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.2.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.2.0_x64-setup.exe.sha256
```

正式下载附件的哈希以该 Release 的 `SHA256SUMS.txt` 和 `manifest.json` 为准。校验值用于检查文件一致性，不替代发布者签名。

推荐从现有 24–70 mm 示例开始：

1. 在“示例与学习”打开“24–70 mm · 双镜组教学变焦”。
2. 进入“调校 → 变焦与对焦工作台”，运行“全焦段扫描”，查看曲线和各位置诊断。
3. 切换“生成变焦补偿轨迹”，指定前组为变倍组、后组为补偿组，运行并检查复核结果。
4. 点击节点查看实际光路；全部通过后，可转换为命名配置，再继续编辑和扫描。
5. 点击“将完整记录保存到项目”，再保存 `.oos.json`。重开后可查看历史结果；采纳前需重新运行完整任务。

按 F1 查看帮助，Ctrl+K 搜索功能。详细操作及 400 mm 对焦设置见 [工作台教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/manual/study.md)；首次使用可先阅读 [新手教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/manual/start.md)。

## 验证与反馈

本轮 **65 项前端测试、88 项 Rust / 桌面测试**、Clippy 检查和生产构建通过。已验证扫描记录保存恢复、候选采纳及无改善候选禁止采纳；既有衍射与成像独立验证通过。Windows 主程序启动响应正常；源码敏感信息扫描未发现问题。

24–70 mm 示例的 13 个全焦段扫描位置、7 个补偿轨迹位置通过声明验收。补偿轨迹从 17×17 提高到 33×33 瞳采样后，最大 RMS 变化约 **0.0165 μm**；抽取三个位置与 RayOptics 独立对照，交点误差小于 `1e-9 mm`。

多配置联合优化验证了全部配置的逐视场保护；400 mm 示例完成无限远、100 m、约 31.62 m 和 10 m 的固定传感器对焦验证。已有 1.1 变焦关键配置的 RMS 与历史基准一致。上述结论仅针对记录中的处方、视场、波长和采样条件，不作为任意镜头的精度保证。

详细证据见 [工作台数值验证](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/validation-study-1.2.json) 与 [1.2 发布验收](https://github.com/ayr1k/OpenOpticSim/blob/v1.2.0/docs/validation-release-1.2.json)。下载文件的构建状态以附件 `manifest.json` / `build-report.json` 为准。
