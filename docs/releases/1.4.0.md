# OpenOpticSim 1.4.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

构建与本地验证日期：2026-10-20。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.4.0/OpenOpticSim_1.4.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.4.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

保存设计任务 → 选择或自动比较经典结构 → 比较三组玻璃并重新优化 → 验收传感器实际覆盖 → 检查逐视场画质报告 → 保存项目、导出报告和技术图纸。

- **统一设计任务**：焦距、F 数、传感器、最大长度、RMS 与搜索预算随项目保存。可显式应用到当前镜头的目标和约束，不通过缩放图形假装改变焦距。
- **自动设计升级**：Tessar、Planar、分离式双高斯与 Sonnar 型可自动比较；最多三个确定性起点。可选 N-BK7/N-F2、N-BAK4/N-SF5、N-SK16/N-SF10 三组玻璃，各组合重新缩放与优化几何；满足约束优先于较低平均 RMS。
- **传感器覆盖验收**：按实际主光线像高逐步扩展到短边、长边与角落，33×33 采样必须通过。不可达、遮挡和求解失败不会被当作通过。
- **画质验收报告**：位于“画质”，记录实际像高、RMS 17→33 变化和可选 10/30/50 lp/mm S/T MTF。模型超限、采样未收敛与未计算明确区分，支持导出带完整处方的 JSON。
- **计算任务管理**：统一队列支持 1/2 个并行任务、取消、暂停和恢复启动新任务；保留引擎内部并行与缓存。现有变焦、对焦、镀膜、版本比较与 PDF 导出均保留。

完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/CHANGELOG.md)。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，具体最低系统兼容尚未完成独立矩阵验收。
- 下载资产：`OpenOpticSim_1.4.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者，运行软件请选择 `.exe` 安装包。
- 安装包包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名。干净、无 WebView2 的 Windows 断网安装尚待实际验收，不将“构建成功”描述为该测试已通过。
- 项目文件保留在用户选择的位置。升级前建议备份自己的 `.oos.json`；不要将未保存的内存状态作为唯一副本。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.4.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.4.0_x64-setup.exe.sha256
```

正式下载附件的哈希以该 Release 的 `SHA256SUMS.txt` 和 `manifest.json` 为准。校验值用于检查文件一致性，不替代发布者签名。源码内较早的本地准备记录仅作为历史证据，不作为新下载文件的校验依据。

打开软件后按 F1 查看帮助，Ctrl+K 搜索功能；推荐从“单透镜”或“双胶合探索”开始，再阅读 [新手教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/docs/manual/start.md)。

## 适用范围与已知限制

- 自动设计是经典拓扑与有限玻璃池上的局部搜索，不保证全局最优。全画幅 / 大光圈目标可能没有通过候选，应调整结构、孔径、长度或目标。通过几何验收不代表 MTF、装配公差或制造可行性通过。
- 玻璃搜索替换种子模型中的两类材料，不是每片玻璃独立穷举；材料波段仍按目录校验。
- 队列暂停不暂停已经运行的数值求解；任务记录仅保留当前会话，尚无求解器断点续算、GPU 或 CPU 使用率上限设置。


- 可见光、旋转对称、顺序折射、有限 / 无限物距、平面传感器；具体范围以 [STATUS](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/docs/STATUS.md) 和 [COVERAGE](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/docs/COVERAGE.md) 为准。
- PSF / MTF 使用限定范围的标量模型，需关注收敛与适用性；瞳求解失败不等于物理遮挡。
- 成像预览为局部平面目标，不是完整三维摄影场景或整幅空间变化渲染。
- PDF 图纸是名义设计记录，未指定的公差、表面质量、镀膜和装配要求不会自动生成。
- 400 mm 示例为用户自建模型的教学修正，约 f/16，不是佳能官方处方或 400 mm f/2.8 复刻。
- 原生文件对话框 / 快捷键的完整人工验收，以及干净 Windows 离线安装仍待补齐。
- 本地验证不替代远程 CI 或全新 Windows 环境验证；线上状态由维护者在 [Actions](https://github.com/ayr1k/OpenOpticSim/actions) 确认。

## 验证与反馈

本轮前端 72 项、Rust / 桌面 95 项测试通过；12 组结构与玻璃组合中，11 组通过 50 mm F/8、6×4 mm 传感器的几何目标（不代表全画幅）。24–70 mm 四个旧配置 RMS 差值均为零，400 mm 的 38,508 条保存回归采样一致；8 个独立衍射算例通过。详细验证状态见 [发布验证记录](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/docs/validation-release-1.4.json)。包括前端与引擎回归、24–70 mm / 400 mm / 经典结构验证，以及新搜索的实际像高覆盖与候选排序检查。构建成功不代表已执行干净 Windows 安装或升级；附件 `manifest.json` 与 `build-report.json` 记录实际构建来源。

数值、UI 与 PDF 的既有证据见 [既有测试报告](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/docs/TEST_REPORT.md)。问题请提交到 [Issues](https://github.com/ayr1k/OpenOpticSim/issues)，注明版本、最小处方、分析条件、复现步骤与错误提示，并删除私人信息。安全问题按 [SECURITY.md](https://github.com/ayr1k/OpenOpticSim/blob/v1.4.0/SECURITY.md) 处理。
