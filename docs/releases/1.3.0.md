# OpenOpticSim 1.3.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

构建与本地验证日期：2026-10-20。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.3.0/OpenOpticSim_1.3.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.3.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

输入设计指标 → 选择经典结构 → 分阶段生成候选 → 检查约束和覆盖范围 → 比较玻璃与色差 → 分析镀膜直透能量 → 保存处方、导出报告与名义技术图纸。

1.3 保留既有扫描、变焦、版本比较和画质分析工具，增加以下功能：

- **从指标创建设计**：Tessar 型、Planar 型、分离式双高斯和 Sonnar 型原创起点；设置焦距、F 数、测试视场、传感器、总长和逐视场 RMS。支持 1–3 个确定性起点，以及小孔径/小视场到完整目标的分阶段搜索。最终检查通过后才可创建项目。
- **优化器改进**：单处方与多配置均支持最多 32 个活动变量；单处方增加并行双侧导数、按变量边界缩放和缩短试步。多配置搜索增加连续约束罚项，允许从未满足目标的有效光路逐步接近目标，最终仍执行严格约束和逐视场保护。
- **镀膜与透射**：编辑每面最多 32 层无吸收介质膜；按真实子午光线入射角计算 S/P 直透能量，比较未镀膜情况并导出逐面报告。膜层随原生项目和版本保存，PDF 增加名义膜层参数页。
- **材料与学习**：33 种有来源、有效波段和 SHA-256 记录的离线玻璃；增加材料解释和双胶合消色差教程。四种经典结构生成结果作为独立示例分发。
- **计算复用**：原生进程使用精确输入键复用已收敛 PSF，最多 8 项、PSF 样本总计 64 MiB；MTF 与测试图共享结果。直接衍射不再固定最多 8 个线程。缓存不放宽采样和收敛要求。
- **界面与帮助**：新入口位于“设计”菜单，已有入口保留；25 章离线帮助可通过 F1 和 Ctrl+K 查阅。

完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.3.0/CHANGELOG.md)。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，最低系统兼容仍未完成独立矩阵验收。
- 下载 `OpenOpticSim_1.3.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者。
- 包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名；本地构建和启动检查不等同干净 Windows 断网安装验收。
- 升级前保存并备份 `.oos.json`。旧项目可继续读取；含镀膜的新项目应使用 1.3 或更高版本，CSV 不携带镀膜。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.3.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.3.0_x64-setup.exe.sha256
```

哈希以同一 Release 的 `SHA256SUMS.txt` / `manifest.json` 为准；校验值不替代发布者签名。

推荐先打开 Tessar 50 mm 教学示例，阅读[指标设计教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.3.0/docs/manual/synthesis.md)，再尝试修改要求。[消色差教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.3.0/docs/manual/achromat.md)解释玻璃选择与验证步骤。

## 适用范围与已知限制

- **指标设计不是任意要求的全自动成品镜头设计。** 四种公开示例按 50 mm、F/8、5° 半视场验证名义几何成像；即使传感器为 36×24 mm，也没有因此验证全画幅角落。真实可制造性、MTF、公差、温度与杂散光仍需额外分析。
- 经典结构数值起点为原创，不是 ZEISS 或其他厂商处方。Planar 与双高斯属于相关结构家族，软件提供胶合内组与分离内组两种起点；材料目前固定，尚未加入离散玻璃联合搜索。
- 镀膜限常折射率、无吸收介质层和子午直透路径；不含鬼影、粗糙度、吸收、一般偏振传播或膜层相位对 PSF 的影响。镀膜不会直接改变现有 MTF/测试图。
- 32 变量不保证找到全局最优。初始几何无效、无可用光路或目标与结构不相容时仍可能失败；失败光线不作为零误差。
- 缓存加速用于同一原生进程内的重复输入；修改处方/波长/模型/采样会失效。冷启动性能依镜头、分析模型和硬件而异，不承诺统一倍数。GPU 加速尚未加入。
- 原有标量衍射适用范围和收敛门槛不变；测试图仍是局部平面目标。24–70 mm 为小像场教学变焦，400 mm 为用户处方修正示例，均不是商用镜头复刻。
- 标签和 GitHub Release 由维护者发布；本地验证不替代远程 CI、完整原生对话框人工验收或干净 Windows 安装测试。

## 验证与反馈

本轮验证包括四种经典结构的独立 RayOptics 求交/折射对照、保存重开一致性、不可满足总长的拒绝、镀膜解析基准与能量守恒、32 变量边界、缓存与未缓存结果一致性，以及既有变焦、400 mm 和衍射回归。详情见 [1.3 验收记录](https://github.com/ayr1k/OpenOpticSim/blob/v1.3.0/docs/validation-release-1.3.json)；安装附件以其 `build-report.json` 为准。

反馈请提交到 [Issues](https://github.com/ayr1k/OpenOpticSim/issues)，附版本、最小处方、分析条件、复现步骤及错误提示，并删除私人信息。安全问题按 [SECURITY.md](https://github.com/ayr1k/OpenOpticSim/blob/v1.3.0/SECURITY.md) 处理。
