# 1.5 自动设计与约束恢复技术说明

## 求解顺序

保留用户选定变量、上下限和锁定状态。每个投影试步先处理玻璃实体和空气跨度（包括跨独立光阑跨度），再用选中曲率的数值近轴导数做有界最小范数焦距修正，最后按新入瞳调整允许变化的光阑半径。小步回退防止焦距修正发散；投影循环有固定上限。像距不参与焦距修正。

厚度恢复针对采样最小值增加 `max(1e-4 mm, minimum*1e-3)` 的内部余量。采样只用于建议修复量，最终仍使用原有连续区间间隙认证。无法认证、超边界或无解保持失败。LM 的导数和试步均使用同一恢复映射；这会使目标成为分段光滑函数，不保证全局收敛。

硬规格违反量优先于组合残差；无效追迹不作为零残差。完整通过候选以 33×33 验收并保留，最终若当前解失败或已保存可行解更好，则返回保存的可行解。画质保护以最初有效处方为基准；若原处方无效且能够恢复，则报告注明以恢复后处方为起点。

## 搜索空间与预算

四个原有经典结构、三个目录玻璃对、1–3 个确定性弯曲起点保留。扩展模式增加三个操作：在已有空气间隙内移光阑、后置正校正片、前置负透镜；每次最多增加一片。每个玻璃体可单独换成其他两组中的同类目录材料，新增材料快照索引，避免更改共享材料的其他镜片。每次变体均从处方重新求解。

基础延拓为四分之一、二分之一、全孔径/视场；阶段抛出追迹或几何错误时，在最后完成阶段与失败阶段之间插入中间目标，最多两次恢复。通过部分阶段不能作为完整任务通过。搜索按经典结构轮流分配预算，优先原始组合和结构变体，然后材料变体；预算范围 1–240。没有任意多片增删、同时全玻璃组合搜索或全局最优保证。

## 持久化边界

`synthesize` 保留完整一次调用接口。`synthesize_step` 一次执行一个确定性结构/材料/初值组合，返回 `checkpoint` 和候选视图。断点 `engine_version=1.5.0-search1` 包含完整任务、完成游标、总数、全部尝试摘要和最多 8 个候选；候选迭代历史清空以限制项目大小，几何处方与验收仍保留。

前端在每个完成尝试后写入工作区；普通保存将其写入 `.oos.json`。取消当前尝试不推进游标。恢复检查引擎格式、完整任务、预算/游标，并对保留候选重做几何、光谱/物距/视场一致性、实际规格和 33×33 追迹验收，不直接相信保存的通过标记。它不是迭代级内存快照；跨引擎格式不能续算。

## 验证证据与比较限制

- `validation-benchmark-1.5.json`：固定 12 个目标，v1.4 4/12，v1.5 9/12；9 个通过方案均追加 49×49 与独立 RayOptics 交点/折射对照。
- `benchmark-design-1.4.json` 和 `benchmark-design-1.5.json`：原始结果、可执行文件哈希、目标与耗时。冻结 v1.4 CLI 哈希与其已有发布构建报告一致。
- 两版用户迭代数相同，但 v1.5 有额外恢复工作且使用明确的 0.5/0.1 mm 厚度约束，v1.4 按种子缩放。不是等算力对照；数据不能外推为一般成功率，也不证明每个单项变化的独立贡献。
- `validation-design-1.5.json`：六个历史示例 RMS 不变；结构变化、独立玻璃替换、断点 JSON 往返、已完成搜索重验、不可达长度拒绝。
- `release15.rs` 与前端回归：锁定变量、焦距/入瞳/间隙恢复、确定性续算、取消、错误任务/断点、项目往返。
- 快速/离轴 MTF 适用范围、制造公差与场景成像范围没有扩展。
