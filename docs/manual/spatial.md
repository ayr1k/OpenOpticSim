# 三维顺序追迹与光线调试器

在 **设计 → 三维追迹与调试** 打开 OOS-Wollaston v1 的三维顺序追迹工具。

1. 打开单透镜或自己的项目，点击“追迹并检查”。默认五条轴向光线从 z=-100 mm 发射；它们是显式测试光线，并非自动填满入瞳的画质采样。
2. 选择一个表面，设置 X/Y/Z 位移和转角。位移单位 mm，界面转角单位度，计算请求使用弧度。旋转按 Rx、Ry、Rz 顺序，绕表面自身顶点，位置相对原始处方名义顶点。
3. 已在“镜组管理”创建的镜组也会出现在对象菜单。镜组整体绕组首名义顶点旋转并平移，单面位姿先于镜组变换；重叠镜组拒绝计算。展开“发射光线与资源”，编辑起点和方向。方向会归一化。斜光线可同时具有非零 X、Y 分量。零方向会报错。
4. 拖动三维视角滑杆，选择光线，查看每个实际交点、法线、介质折射率、入射/折射角和光程。红色代表失败光线，显示截至最后实际交点；求交失败不会虚构后续路径。
5. 导出可复现请求可交给独立框架 CLI 或 Python 接口执行；导出逐面记录用于诊断。

三维配置随项目保存，支持撤销重做。修改表面名称或顺序后需要重置三维配置，避免位姿套错表面。取消计算或编辑参数后旧结果不会覆盖当前结果。

**能力边界：**三维配置是一份独立实验配置，现有同轴处方保持不变。点列图、优化器、MTF、像差、技术图纸和历史版本比较仍针对原始同轴处方，不能用它们评价这里的偏心倾斜效果。三维工具目前输出显式光线的几何交点与光程，不提供偏心系统瞳瞄准和衍射分析。只按表面顺序追迹，不搜索非顺序反射或鬼影路径。

框架接口还支持圆、椭圆、矩形和环形附加口径，它们与原始有效口径相交。矩形和椭圆尺寸是半宽/半高。传感器可单独移动、倾斜。偏移表面之间的实体碰撞没有自动认证，机械可制造性需另行检查。

框架源代码位于发行源目录 `OOS-Wollaston/`；它有自己的 README、API 手册和测试，复制到其他位置也能构建。独立框架版本为 1.0.0，桌面软件版本为 2.0.0。
