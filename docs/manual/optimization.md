# 带约束优化、画质底线与候选采纳

入口：「调校 → 约束优化」。1.0 将原右侧专业优化设置移到中央工作台，所有变量、锁定、边界、规格约束和报告仍保留。「设计目标」也可按当前设置生成候选。

## 推荐流程

1. 保存当前项目并记录基准版本；先修正几何、瞄准和材料问题。
2. 设置目标焦距和容差、最大总长、最小中心/实体厚度和空气间隔。按需启用目标 F 数、最小后焦距及最大前组有效直径。
3. 打开多表面变量编辑，添加曲率、间隔、A4-A10，或光阑面半径；设置合理上下限，锁定不想改变的参数。最多 32 个活动变量，材料暂不自动更换。1.3 并行估计双侧导数，以变量边界确定尺度；无效试步先缩短，再增加阻尼，最终仍需通过全部约束。初始光路完全失败时需先修复模型。
4. 设置中心、均衡或边缘优先的目标权重，迭代上限和逐视场画质保护。
5. 生成优化候选，查看真实迭代轨迹、停止原因、逐视场取舍和最终检查。
6. 只有全部条件通过才可采纳；否则可保存候选为待改进版本，继续修改约束或处方。

## 保护每个视场

在「画质底线与分阶段视场」启用逐视场保护。将「每个视场相对原设计最多退化」设为 0%，可防止为了降低平均光斑而使某个配置视场变差。

也可限制各视场 RMS、最差视场 RMS、最大绝对畸变、横向色差和最低几何采样通过比例。绝对阈值应从基准设计和实际需求制定，界面默认数值不是通用合格标准。通过比例使用 0-1，例如 0.95 表示 95%。

改变视场数量时逐视场绝对底线会清空并提示；全局规则保留。即使数量没变，改了像高含义后也应重新确认底线。有限物距尚无当前无限远畸变参考，启用该项会无法通过。

## 分阶段扩大视场

启用 50% → 75% → 100% 扩大视场，可从小场逐步求解。每阶段都对照同条件下的原设计，阶段失败就停止，不会冒充全视场完成。

选择「每个设计共用像面，不自动重新对焦」或「每阶段原设计与候选分别重新对焦」，决定是否允许重新寻找各自焦点。重新对焦后的最终处方再次执行全部边界和约束检查。

## 无法采纳时

先读候选顶部的原因汇总，检查表默认过滤未通过项。显示值可能舍入为 0，但连续几何、细采样通光、变量边界或引擎批准状态仍可能未通过。其他行通过不能抵消失败项。

只有显式允许小于 100% 的通光比例时，物理遮挡才能在保护条件内参与优化；瞄准未解、全反射、求交或材料失败始终不当作零误差。局部阻尼最小二乘不保证全局最优，也不保证每次候选都可采用。
