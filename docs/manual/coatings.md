# 镀膜与直透光谱

入口：设计 → 镀膜与透射。镀膜层与表面一起保存在原生 JSON 项目和设计版本中，顺序从物方到像方。CSV 不携带膜层；需要保留镀膜时使用原生格式。

选择表面，加入膜层，设置名称、常数折射率和物理厚度（nm）。最多 32 层，折射率 1–10，厚度 0–10000 nm。可以添加、删除，或清除此面的所有膜层。550 nm 四分之一波长按钮给出 n=1.38、约 99.64 nm 的教学初值，不是厂商工艺配方。

## 查看结果

点击计算实际光线透射率。使用项目全部视场和全部波长，对中心及 ±0.8 瞳半径的三条子午光线进行真实追迹，取得每一面的实际入射角，分别累计 S/P 直透能量，最后取非偏振等权平均。对照列使用完全相同光路上的未镀膜 Fresnel 透射率。

数值只表示这些采样路径，不能标成整幅相对照度或全瞳平均透过率。被遮挡、瞄准失败、全反射或模型不支持的光线会明确显示失败，不以零值混入平均。报告可以导出逐面入射角和 S/P 反射、透射系数；新增波长即可观察光谱变化。

## 模型与限制

采用无吸收、均匀、各向同性介质层的特征矩阵。膜层折射率不含色散，基底玻璃则使用项目材料的波长相关折射率。模型检验每面的 R+T=1；含倏逝场、吸收或全反射的情况返回诊断。

目前不模拟多次反射路径、鬼影、散射、表面粗糙度和整镜头偏振状态。直透分析与几何 PSF/MTF 分离：设置镀膜不会改变既有点列、MTF 和测试图结果，也不会简单通过提高对比度来伪造镀膜成像效果。镀膜相位和瞳振幅进入 PSF 需要额外的矢量/波动验证。

理论依据：特征矩阵的场连续性与光学导纳形式，参考 [Oregon 光学讲义](https://atomoptics.uoregon.edu/~tbrown/files/relevant_papers/optics-notes.pdf)。解析测试包含裸界面 Fresnel、Brewster 角、理想单层零反射和多角度能量守恒。
