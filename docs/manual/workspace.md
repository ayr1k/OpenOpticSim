# 界面导航、搜索与快捷键

## 按任务选择工具

- 「设计」：设计目标、镜头处方、镜组管理、几何检查。先定义要做什么，再确认几何成立。
- 「画质」：点列图、瞳面图、像差与通光、PSF / MTF、测试图成像。先确认追迹成功，再解释画质。
- 「调校」：对焦扫描、光圈扫描、约束优化。所有改变处方的计算先产生候选，经过复核和采纳才替换当前镜头。
- 「交付」：版本对比、技术图纸 PDF。文件菜单另有保存、另存为和处方 CSV。

## 侧栏与画布

左侧整枚镜片和单面列表相互独立滚动；选中会联动画布和右侧。列表支持名称、材料与 S12 这类面号搜索。方向键可在列表中移动选择。中间分隔条可拖动，也支持方向键及 Home/End 调整比例。

右侧「镜片 / 面」编辑选中的对象，「摄影与分析」编辑光阑、物距、传感器、波长和权重。基础模式提供整枚镜片编辑；专业模式提供单面曲率、材料系数、K 与 A4-A10。基础和专业使用同一计算模型，切换不会变换处方。

画布滚轮缩放、拖动平移；使用画布工具条放大、缩小、适应全部和聚焦选中镜片。等比例显示不会通过缩放实现目标焦距。侧栏收起和列表比例保存在本机；恢复布局不改变镜头数据。

## 随时查阅帮助

顶部「帮助」打开完整目录；「当前页面帮助」或 F1 打开正在使用的工具说明。帮助可按全文搜索，例如“无法采纳”“Sellmeier”“角落”。多个词用空格分隔时要求全部匹配。文档在安装包内，断网也可查阅；外部来源链接需要网络。

Ctrl+K 打开功能搜索，可直接前往工具或文档。搜索区输入普通中文名称，不需要知道内部菜单位置。

## 快捷键

- Ctrl+N：新建项目。
- Ctrl+O：打开 JSON / CSV。
- Ctrl+S：保存项目；Ctrl+Shift+S：另存为。
- Ctrl+Z：撤销；Ctrl+Shift+Z：重做。输入框内优先保留文本编辑行为。
- Ctrl+K：查找功能与帮助。
- F1：当前工作台帮助。
- Esc：关闭当前弹窗；耗时计算使用面板内的取消按钮。

编辑输入框后按 Enter 或移出输入框提交。不要把本机自动恢复当作已经写入文件；项目名旁显示是否有未保存修改。


## 计算任务队列（1.4）

分析工作区上方可展开「计算任务」。默认串行启动任务，减少不同面板争用计算资源；可改为同时两个任务。单个引擎操作仍使用其内部并行，所以并发任务数不等于 CPU 线程数，也不是 CPU 使用率硬限制。

排队时取消不会启动引擎。运行时取消会通知工作线程，直到线程退出才释放队列名额，旧结果不会被成功回填。暂停队列仅阻止启动新任务，正在运行的计算继续；恢复后按队列顺序执行。任务视图保留本次会话最近 20 项历史及所有未结束任务，关闭程序不恢复队列。精确输入 PSF 缓存仍按 1.3 的规则使用，缓存命中同样遵守取消检查。
