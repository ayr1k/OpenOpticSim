# PSF、MTF 与采样收敛

1.3 性能：原生应用在同一进程内复用已收敛结果，精确比较处方、材料、波长、像面、模型与采样设置。最多缓存 8 项且 PSF 样本不超过 64 MiB，超出后淘汰最旧项。重复 MTF 和测试图可受益，修改输入自动失效。直接离轴积分不再限制为最多 8 个线程。没有降低收敛标准，也没有统一的冷计算提速保证；开发服务器每次启动 CLI，不共享原生进程缓存。

入口：「画质 → PSF / MTF」。先检查几何和通光，再选择模型、视场、单色/多色和采样上限，点击「计算 PSF / MTF」。

## 选择方法

快速模型适用于小视场 ±0.15 rad，约 ±8.59°，还要求参考球方向正弦不超过 0.25 等检查。不能因为几何能到 40°，就假设快速 MTF 也支持。

「离轴 · 平面像面 Kirchhoff」使用实际参考球、瞳映射、遮挡和光线管振幅，在最终平面传感器直接积分传播距离。可研究更大离轴视场，但仍要求稳定可逆瞳映射、空气像方、正参考距离、横向方向正弦不超过 0.85 和像面 Nyquist 合格。

35 mm 全画幅示例的角落应使用直接法。400 mm 工作区的约 3.1°角落可能满足快速范围，但比较时仍应显式使用同一模型。

## 收敛与适用性

采样上限 128 适合初步检查，256 用于更细验证。软件比较相邻瞳采样，检查 MTF 最大变化 ≤0.015、PSF L1 ≤0.04、相邻相位步 ≤0.25 波长、外侧 10% 窗口能量 ≤0.005；直接法还要求 Nyquist 比例小于 1。

只有通过门槛才返回可用结果。不通过应查看原因：可能散焦、像差太大、窗口不够、瞳映射复杂或采样不足，不应把失败改成零像差。可取消耗时任务；修改输入会使旧结果失效。

## 读图

PSF 是单位计算窗口能量的点扩散函数。对数显示只改变显示亮度，不改变光学计算。视窗可查看中心 128、256 或完整区域；下方标尺使用 µm。

MTF 横轴为空间频率 lp/mm，纵轴为调制度传递。S 为弧矢 X 方向，T 为子午 Y 方向。切换频率上限只改变显示，不重新优化镜头。高频对采样更敏感；不要用不同尺度或不同波长权重比较。

## 多色与限制

多色按项目权重非相干叠加；每波长计算窗口内归一化，不代表总光通量或真实传感器响应。模型是标量近似，不包含 Fresnel 界面损失、偏振或镀膜。

边缘能量是有限窗口指标，不是缺失能量的严格误差界。图像看起来清晰不代表任意孔径/视场都经过验证。点击「导出 MTF 报告」保留处方、方法和收敛信息。
