# 点列图、像差与追迹诊断

## 点列图与 RMS

「画质 → 点列图」展示各视场、各波长在平面像面上的交点。图内所有波长围绕共同质心显示，保留横向色差；对比时使用共同物理尺度，不按每幅图单独放大。

单色 RMS 为该波长交点相对自身质心的均方根半径；多色 RMS 使用波长权重和共同质心，包含横向色差。它是几何指标，不包括衍射。

失败样本不作为零误差。出现部分失败时，即使剩余光线的 RMS 很小，也不能据此确认镜头良好。缺少完整波段时不显示完整多色指标。

## 像差与通光

入口「画质 → 像差与通光」。可查看多色 RMS、横向色差、弧矢/子午焦移、近轴纵向色差、每波长质心和畸变。

- 横向色差：配置波长质心 Y 的跨度。
- 场曲/像散：参考 d 线附近微分光束相对当前像面的弧矢/子午焦移，两者差异体现像散。
- 纵向色差：不同波长无限远近轴后焦距相对 d 线的偏移。
- 畸变：无限远以 f·tan(θ) 为参考；有限物距暂不报告该基准。

## 区分物理失败与求解失败

诊断按视场、波长、阶段、表面和原因统计。物理失败可能是口径遮挡、全反射或未命中；数值失败可能是瞄准未解、曲面迭代不收敛或材料波段无效。

瞄准阶段的试算不是实际物理光路，不会画到剖面上。成功瞄准后重新执行真实追迹；失败路径只画到实际终止位置。点击失败项或瞳面点可定位。缺少路径表示未得到可绘制的物理解，不能补一条直线代替。

## 近轴指标

有效焦距、后焦距、入瞳与出瞳来自一阶矩阵。F 数用有效焦距和入瞳直径计算，不能直接以实体光阑直径代替。无光焦度或瞳在无穷远时可能未定义；无限远负后焦距表示后方近轴实像条件不成立，应先修改处方。


## 全视场画质验收报告（1.4）

进入「画质 → 画质验收报告」，先生成几何报告，再按需要勾选逐视场 MTF。几何使用同一处方与当前固定像面，比较 17×17 和 33×33 瞳采样的多色 RMS；变化不超过 max(0.01 µm, 1% RMS) 且没有失败样本时才标记收敛。这个采样门槛不是任意镜头的精度保证。

报告按实际像高列出中心至边缘的 MTF，在 10、30、50 lp/mm 处线性插值弧矢和子午曲线；超过离散频率范围不外推。快速模型超限可切换离轴平面像面模型，但模型失败或未收敛仍显示未验证。几何收敛不代表衍射收敛，衍射收敛也不代表达到了某个产品 MTF 规格。

导出的 JSON 包含完整处方、波长、像面条件、几何采样、覆盖证据、衍射质量数据及失败原因。与其他方案比较时先使用现有「版本对比」统一传感器、视场、光谱和对焦条件；不同像面或视场下的平均 RMS 不可直接作为改进证据。已有像面对焦扫描用于观察共用像面的取舍，不将每个视场各自的最佳焦点拼成一幅平面图像。
