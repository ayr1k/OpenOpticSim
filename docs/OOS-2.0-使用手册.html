新手教程：完成第一份镜头设计

适用版本：OpenOpticSim / OOS 1.0。软件在本地运行，无需账户；保存项目和计算不依赖网络。建议首次使用从教学示例开始。

第一步：打开示例并保存副本

点击左下角「示例与学习」，打开「双胶合探索」或「400 mm · 传感器覆盖工作区」。示例中的观察任务介绍它适合研究什么；400 mm 工作区为修正后的小光圈实验设计，不是佳能商品镜头处方。

顶部「文件与导出 → 另存为项目」保存自己的 .oos.json 副本。也可「新建项目」从空白或模板开始。打开另一个项目前，软件会询问是否保存未保存的编辑。

第二步：认识工作区

左侧分别选择整枚镜片与单个表面；中间是子午光路和分析工作台；右侧分为「镜片 / 面」与「摄影与分析」。四组工作流程为「设计、画质、调校、交付」，每组下方列出对应工具。使用 Ctrl+K 查找功能，F1 打开当前页面帮助。

左侧、中央和右侧独立滚动。透镜列表与表面列表还可以分别滚动；拖动中间分隔条调整两者比例。上方按钮可收起侧栏和恢复布局。

第三步：确认目标和传感器覆盖

在「设计 → 设计目标」设置传感器尺寸和视场定义。第一次练习可沿用示例，不必立刻切换全画幅角落。需要检查整个传感器时选择「跟随传感器：中心、边中点与角落」。查看每个检查点是通过、遮挡、求解失败还是未验证。

改变目标焦距不会直接缩放镜头。有效焦距来自实际曲率、材料和间隔；目标供优化器约束使用。参见视场与传感器。

第四步：调节光圈并对焦

右侧「摄影与分析」修改光阑半径，按 Enter 或移出输入框提交。拖动光阑时显示低采样预览，停止后重新精细计算。光阑半径不是入瞳半径；显示的 F 数按近轴入瞳计算。

先在「设计 → 几何检查」排除相交，再到「画质 → 像差与通光」查看失败光线。点击右侧「自动对焦」生成候选，查看复核结果，全部通过后「采纳候选」。没有采纳时，当前镜头不会改变。若存在虚像或求解失败，对焦本身无法修复它们。

第五步：查看画质

在「画质 → 点列图」观察中心和边缘的光斑。进入「PSF / MTF」，先选中心、多色和快速模型；大视场改用直接 Kirchhoff。点击计算，检查收敛状态，再比较边缘。不能把几何 RMS 小等同于 MTF 一定高。

「测试图成像」显示各视场局部平面测试目标经过 PSF 后的近似图像，不是完整三维摄影场景。参见衍射分析和测试图成像。

第六步：保存基准、尝试修改

顶部「记录版本」保存当前设计基准。修改一项参数后，在「交付 → 版本对比」选择 A/B，统一测试条件，计算同尺度结果。撤销 Ctrl+Z、重做 Ctrl+Shift+Z 用于当前会话；命名版本随项目文件保存，适合跨会话回看。

第七步：导出和重开

「交付 → 技术图纸 PDF」导出完整名义处方与图纸。需要重新编辑时保存 .oos.json；PDF 本身也内嵌一份精确源项目。保存后用「打开」重新载入，确认处方、视场、版本和镜组仍在。

进一步学习：编辑镜片、对焦扫描、光圈扫描、约束优化。遇到红色提示先查报错排查。

界面导航、搜索与快捷键

按任务选择工具

- 「设计」：设计目标、镜头处方、镜组管理、几何检查。先定义要做什么，再确认几何成立。

- 「画质」：点列图、瞳面图、像差与通光、PSF / MTF、测试图成像。先确认追迹成功，再解释画质。

- 「调校」：对焦扫描、光圈扫描、约束优化。所有改变处方的计算先产生候选，经过复核和采纳才替换当前镜头。

- 「交付」：版本对比、技术图纸 PDF。文件菜单另有保存、另存为和处方 CSV。

侧栏与画布

左侧整枚镜片和单面列表相互独立滚动；选中会联动画布和右侧。列表支持名称、材料与 S12 这类面号搜索。方向键可在列表中移动选择。中间分隔条可拖动，也支持方向键及 Home/End 调整比例。

右侧「镜片 / 面」编辑选中的对象，「摄影与分析」编辑光阑、物距、传感器、波长和权重。基础模式提供整枚镜片编辑；专业模式提供单面曲率、材料系数、K 与 A4-A10。基础和专业使用同一计算模型，切换不会变换处方。

画布滚轮缩放、拖动平移；使用画布工具条放大、缩小、适应全部和聚焦选中镜片。等比例显示不会通过缩放实现目标焦距。侧栏收起和列表比例保存在本机；恢复布局不改变镜头数据。

随时查阅帮助

顶部「帮助」打开完整目录；「当前页面帮助」或 F1 打开正在使用的工具说明。帮助可按全文搜索，例如“无法采纳”“Sellmeier”“角落”。多个词用空格分隔时要求全部匹配。文档在安装包内，断网也可查阅；外部来源链接需要网络。

Ctrl+K 打开功能搜索，可直接前往工具或文档。搜索区输入普通中文名称，不需要知道内部菜单位置。

快捷键

- Ctrl+N：新建项目。

- Ctrl+O：打开 JSON / CSV。

- Ctrl+S：保存项目；Ctrl+Shift+S：另存为。

- Ctrl+Z：撤销；Ctrl+Shift+Z：重做。输入框内优先保留文本编辑行为。

- Ctrl+K：查找功能与帮助。

- F1：当前工作台帮助。

- Esc：关闭当前弹窗；耗时计算使用面板内的取消按钮。

编辑输入框后按 Enter 或移出输入框提交。不要把本机自动恢复当作已经写入文件；项目名旁显示是否有未保存修改。

计算任务队列（1.4）

分析工作区上方可展开「计算任务」。默认串行启动任务，减少不同面板争用计算资源；可改为同时两个任务。单个引擎操作仍使用其内部并行，所以并发任务数不等于 CPU 线程数，也不是 CPU 使用率硬限制。

排队时取消不会启动引擎。运行时取消会通知工作线程，直到线程退出才释放队列名额，旧结果不会被成功回填。暂停队列仅阻止启动新任务，正在运行的计算继续；恢复后按队列顺序执行。任务视图保留本次会话最近 20 项历史及所有未结束任务，关闭程序不恢复队列。精确输入 PSF 缓存仍按 1.3 的规则使用，缓存命中同样遵守取消检查。

项目文件、保存与数据交换

新建、打开和保存

「新建项目」可选择空白或教学模板，设置名称、传感器、无限远/有限物距和传感器联动视场。空白项目先添加镜片，再进行光学分析。

「打开」接受原生 .oos.json 与 OOS 处方 CSV。结构合法但几何存在问题的草稿可以打开修复。无效数值、错误材料索引、不支持的格式版本会明确拒绝。

「保存项目」写回当前原生文件；「文件与导出 → 另存为项目」选择新位置。CSV 导入后首次保存为新的原生项目。原生桌面保存先写同目录临时文件、同步后原子替换；取消对话框不会写入。

保存哪些内容

原生项目包含全部表面、材料快照、光阑、物距、传感器、视场与波长。工作区还可保存命名版本、对焦设置、优化变量和约束、镜组、光圈设置及完整扫描摘要。大型 PSF 数组、临时点选瞳面光路和对比计算不会塞入项目文件，需要重新计算或单独导出报告。

文件上限 4 MB，命名版本最多 20 个。版本不嵌套历史。达到限制时删除不需要的版本，或另存为独立项目；不要手动截断 JSON。

格式兼容性

1.0 继续读取 v1/v2/v3。独立机械边缘需要 v2；像高视场及新画质保护使用 v3。新软件不会将 v3 编辑成 v2。旧软件可能不支持 v3，应保留原始文件副本。

OOS CSV 第一行 #oos 元数据保留材料与工作区，后续是表面表格。它不是通用商业光学处方格式；删除元数据会丢失重建完整模型需要的信息。导出报告 JSON 是结果记录，不应当作原生项目打开。

自动恢复和版本

每次编辑会尝试写入本机自动恢复，启动时优先恢复。它不等于外部文件已保存，也不应代替手动保存。命名版本和撤销历史不同：撤销栈属于会话，命名版本保存在项目内。参见版本对比。

技术图纸与源项目

PDF 附件 project.oos.json 是导出时冻结的完整源数据，含原始精度；它的 SHA-256 写在总览页。支持附件的 PDF 阅读器可提取后在 OOS 打开。analysis.json 记录本次分析摘要，省略大型光线/点列/PSF 数组。详见技术图纸。

搭建镜头、整枚编辑与专业表面

从实体镜片开始

左下选择双凸、平凸、双凹、弯月或胶合双片，点击「添加镜片」。软件插入一整组表面和空气间隔。也可添加单个表面，适合专业处方录入。当前最多 100 个表面。

选择左侧透镜后，在右侧基础模式编辑材料、中心厚度、镜后间隔、有效直径、机械外径和前后面形状。胶合组共享中间光学面，修改时保持连续材料结构。复制和删除整组会同时处理光阑索引和后续位置；表面数量改变时清空旧镜组与优化变量，避免引用错面。

曲率和材料约定

专业模式中曲率 c 的单位为 1/mm，曲率半径 R=1/c。c=0 是平面；正曲率表示球心位于顶点 +Z 侧。从左向右追迹，因此通常双凸镜前面正、后面负。不要把半径 mm 直接填入曲率框。

每面「面后材料」表示通过该面后所处的介质，空气通常为材料 0。独立正透镜一般为：前面后玻璃、后面后空气；胶合双片则依次为玻璃 A、玻璃 B、空气。材料顺序错误会显著改变光焦度。

厚度是当前面顶点到下一面顶点的距离；最后一面的厚度是到传感器的距离。第一顶点固定为 Z=0，其余坐标逐项累加。半口径是有效半径，不是直径。

非球面和光阑

专业模式提供圆锥常数 K 与 A4、A6、A8、A10。系数分别乘以 r 的 4、6、8、10 次幂，长度单位为 mm。很小的系数在大口径上也可能产生很大矢高，建议逐项修改并检查定义域和几何。

点击「设为光阑」指定实体光阑所在表面，可与折射面重合。只改变光阑索引不会自动改变其他有效口径。摄影区的光阑滑块修改该面的有效半径；实际可用通光仍取决于全部表面。

机械边缘

机械外径和有效直径分开编辑，可制作带方边环带的“折角”镜片。环带只改变实体轮廓，超出有效口径的光线依然被挡住。参见机械与几何检查。

编辑后可 Ctrl+Z 撤销；先保存版本再尝试较大改动。焦距是计算结果，不能通过画布缩放或目标焦距输入直接实现。

机械边缘、尺寸和几何检查

光学口径与机械外径

有效口径限定参与光学追迹的区域；机械外径描述镜片实体边界，可以大于有效直径。基础模式按直径显示；原生格式 semi_aperture 和 mechanical.semi_diameter 均保存半径，单位 mm。

「方边环带」将有效口径之外的轮廓保持为边界矢高，形成类似折角的肩部。「随曲面环带」将曲面延续到机械边界。未设独立边缘时，实体径向范围跟随有效口径。

环带不是可折射的额外光学区域，不会扩大实际通光。要增加光学口径，必须修改有效口径并重新验证。

检查顺序

在「设计 → 几何检查」查看每段实体或空气间隔。检查包括曲面定义域、中心厚度、边缘厚度、两面相交与连续分离状态。点击诊断可定位到对应面。

中心厚度只测轴上；即使中心为正，边缘仍可能相交。最薄数值是采样估计；通过状态使用引擎的区间检查，二者含义不同。处于数值边界或无法证明分离时会保留未通过诊断。

机械尺寸变大可能使此前有效的光学面超出定义域，或导致实体相交，应修正曲率、中心厚度、外径或边缘形式。不要只调大有效口径来消除遮挡而忽略实体厚度。

与优化和图纸的关系

约束优化可以限制中心厚度、最薄实体和最小空气间隔。图纸分别记录有效直径、机械直径、轴向长度、采样最薄值和连续检查状态。几何通过不代表通光和像差通过。

当前不提供加工倒角、胶层厚度公差、装配基准、机械强度和完整公差链。技术图纸是名义光学设计记录，未指定项目不会自动补全。

材料目录、常数折射率与 Sellmeier

使用真实玻璃

右侧「镜片 / 面」的材料目录可搜索并应用内置玻璃快照；当前目录包括 33 种有来源记录的玻璃。基础模式可按镜片选择，专业模式可编辑材料系数与有效波段。

目录选择后，系数和来源随项目保存，因此打开旧项目不依赖商业材料库或在线查询。目录材料不代表特定生产熔次、温度或实物透过率。

两种色散模型

- 常数 n：所有有效波长使用同一折射率，适合教学和解析验证。

- Sellmeier：n² = 1 + Σ Bi λ²/(λ²-Ci)。λ 使用 µm，Ci 使用 µm²；保存为三项 B 数组和三项 C 数组。

例如界面波长 587.5618 nm，在 Sellmeier 中使用 0.5875618 µm。单位误用会导致严重错误。使用材料前检查项目所有波长是否位于其有效范围。

来源与可重现性

每种材料包含名称、常数 n、可选 Sellmeier 系数、range_nm 与 source。选择 Sellmeier 时实际追迹使用色散系数，而不是把 n 当作 d 线强制值。材料编辑会影响所有引用该材料索引的表面。

合成教学 crown/flint 是教学材料，不应冒充真实商品玻璃。仅按镜片示意图猜测材料无法复原真实镜头性能。PDF 材料页列出全部材料快照和来源；精确原值保留在项目附件。

消色差操作请阅读双胶合消色差教程。

消色差入门：从玻璃选择到双胶合验证

先分清两种色差

轴向色差是不同波长在轴上的最佳焦点不同。横向色差是同一像面上不同波长的像高不同，通常在边缘更明显。移动传感器只能选一个折中像面，不能同时消除这两种色差。

打开“双胶合探索”，先保存为基准版本。使用 F=486.1327、d=587.5618、C=656.2725 nm 等权重，保持相同传感器、视场和采样。进入“像差与通光”观察轴向/横向色差，再看三种颜色点列的相对位置。改变比较条件会使结论失效。

读懂材料库

“查找真实玻璃材料”提供 33 种离线玻璃及来源链接。nd 是 d 线折射率，Vd=(nd−1)/(nF−nC) 是阿贝数。Vd 大表示 F–C 的主色散较小，不代表所有波段都更好。玻璃分组文字根据 nd/Vd 粗略解释，不能替代厂商加工、热学、化学性质。

常用入门搭配是正光焦度的 N-BK7 和负光焦度的 N-F2。固定总焦距时，用高阿贝数正片抵消低阿贝数负片的主色散。替换玻璃后曲率和厚度并不会自动重新设计，原有成像可能变差。

用薄透镜关系估算初值

两片紧靠时令总光焦度 Φ=1/f，满足 Φ1+Φ2=Φ 及 Φ1/V1+Φ2/V2=0，可得 Φ1=V1/[f(V1−V2)]，Φ2=−V2/[f(V1−V2)]。

例如目标 100 mm，V1≈64.17、V2≈36.37，得到 Φ1≈0.02308 mm⁻¹、Φ2≈−0.01308 mm⁻¹，对应单片近轴焦距约 +43.32 mm 和 −76.44 mm。它只是零厚度、紧靠模型的初值；不能直接当成完整双胶合处方。

在软件中操作

1. 打开双胶合示例，另存项目；把正片换为 N-BK7、负片换为 N-F2。确认胶合界面仅有一个表面，面后材料顺序正确。

2. 从小光圈和中心视场起步，自动对焦。查看几何检查和追迹失败；不要以减少有效光线的方式“降低 RMS”。

3. 在“设计目标”中设置目标焦距和允许误差。在“约束优化”选择三个折射面曲率和像面距离，保留正厚度和最小实体厚度。

4. 保留三条波长；加入横向色差上限、各视场 RMS 上限，并明确共同像面。优化后检查全部约束，记录为候选版本。

5. 扩大光圈、增加边缘视场，重新查看色差与通光，再进行 MTF 收敛检查。用相同尺度、波长、视场和像面条件比较原设计。

若正负光焦度过强，可降低要求或改变结构；增加另一种玻璃或镜片并不保证自动获得复消色差。主色差抵消后仍有二级光谱，部分色散比会影响残差。本版不把上述两片关系称为 APO 设计，也不自动证明三色共焦。

检查学习结果

应能解释：为什么提高折射率不等于消色差，为什么单色优化会掩盖色差，为什么同样的中心表现不代表边缘也合格。保存基准、修改版和分析配置，导出报告供重复验证。

从指标创建设计

入口：设计 → 从指标创建设计；Ctrl+K 搜索“经典结构”，或在本页按 F1。

选择 Tessar 型、Planar 型、分离式双高斯或 Sonnar 型。OOS 提供原创数值起点，借鉴的是镜片/胶合拓扑，不是原厂处方。Planar 与双高斯属于相关结构家族，本软件用胶合内组与分离内组区分两个起点。Tessar 型为四片三组，Sonnar 型为六片三组。

建议的第一次操作

先点击“加载已验证入门任务”：50 mm、F/8、6×4 mm 传感器、150 mm 最大总长、25 µm RMS 上限，并启用玻璃搜索和覆盖验收。保持默认三谱线，先运行一个起点、25 次迭代。确认流程后，再提高要求或扩大视场。生成不会修改正在打开的项目。

开启覆盖验收后，传感器尺寸决定实际像高目标；关闭后才按角度输入测试。36×24 mm 与 6×4 mm 是不同的设计任务，不能由小画幅成功推断全画幅可用。

搜索如何工作

按选定结构建立 N-BK7 / N-F2 起点；使用近轴有效焦距缩放，并为目标孔径调整通光口径与初始间隙。每个起点先在目标四分之一孔径、四分之一视场开始，随后扩展至二分之一和完整目标。每个阶段自动对焦并执行受限局部优化。

可选 1–3 个确定性弯曲起点；每阶段最多 100 次迭代，支持取消。不同起点与三个阶段会分别计数，所以进度中的阶段迭代数可能重新从零开始。

最终检查包括焦距 1% 容差、F 数 3% 容差、总长、中心/实体厚度、空气间隙、逐视场 RMS 和 33×33 全波长几何通光。只有全部通过才允许创建项目。未通过时保留检查项，导出完整报告可保留候选处方供后续研究；计算失败则保留失败原因。

“通过”的准确含义

通过所选几何指标，表示得到可以继续进行分析的名义处方。只有勾选覆盖验收且三处检查点均通过时，才证明这些传感器检查点的声明采样通过。它没有自动通过 MTF、公差、温漂、杂散光、成本、玻璃可采购性或制造可行性审查。开始采购加工前需要另外完成这些验证。

非常快的光圈、大视角、短总长或严苛 RMS 可能与选定结构不相容。软件不会把这些失败隐藏成成功，也不承诺全局最优。可放宽指标、换结构、增加起点，或保存报告后手工调整材料与边界。

1.4 统一设计任务与搜索

在「设计 → 从指标创建设计」设置任务。参数会随 .oos.json 保存，并进入撤销历史。选择「将任务应用到当前镜头」才会改变当前传感器和视场，同时写入焦距、F 数、长度、最差视场 RMS 与覆盖优化约束。只改任务参数不会改变镜片形状。打开「设计目标」可查看实际值；该页焦距、F 数和长度的修改会同步已有任务。手工更改波长、视场或其他优化保护项后，使用同步按钮重新应用任务条件。

新任务默认要求覆盖传感器。此时按实际主光线像高求解短边、长边与角落，角度输入不决定最终视场。若选择只验证指定角度，应取消覆盖要求；报告依然不能宣称覆盖全传感器。采用相同的 F/d/C 等权重光谱，在四分之一、二分之一和完整目标逐步扩大孔径与视场。

可选择自动比较四种结构，或者只尝试一种。自动玻璃选择在三个明确的玻璃对之间比较：N-BK7/N-F2、N-BAK4/N-SF5、N-SK16/N-SF10；并非穷举所有玻璃。每个材料组合重新建立初值并优化，不能只替换折射率后复用旧评分。最大预算为结构数量 × 玻璃对数量 × 起点数量 × 三阶段 × 每阶段迭代数，全部搜索可能较慢。取消不会返回半成品作为已验证候选。

候选表优先显示全部约束通过的方案，再按 RMS 排序。点击候选查看完整检查表；较低 RMS 但机械间隙不满足时仍不能采用。目标没有解时，尝试缩小传感器、收小光圈、放宽总长或更换结构。六乘四毫米传感器的成功示例不能证明全画幅可用。

只有完整生成的结果可以创建项目，创建时保留已验证处方和任务，不自动覆盖原项目。1.5 起，已完成尝试的断点随项目保存。暂停并保存项目，重开后点击“从断点继续”；未完成的单次尝试会重新运行。搜索报告保留最佳 8 个候选、全部尝试摘要和任务设置。

1.5 约束恢复、结构探索和断点

先设置目标与最小中心厚度、最小实体厚度，再选择“保留经典结构”或“扩展结构”。扩展模式在原始结构之外比较移动光阑、后置校正片、前置负透镜；每个变体最多增加一片，没有无限增片或任意自由曲面生成。经典结构仍可单独选择。勾选“镜片级玻璃搜索”后，逐片尝试另外两个同类目录玻璃，其他共享同一材料的镜片不随之改变；胶合片内的每枚玻璃也单独处理。此版本尚不同时搜索多枚玻璃组合。

“最多搜索尝试”限制完整组合数，范围 1–240。默认 36，按结构轮流分配，先原始方案和结构变体，再逐片玻璃变体；预算不够可能尚未覆盖材料搜索。每次尝试有三个基础孔径/视场阶段，失败时最多二次插入中间阶段恢复，再推进完整目标。尝试数、迭代预算、耗时不是同一个量；失败恢复会增加计算量。

优化在允许范围内先修复实体厚度、有效焦距与真实入瞳 F 数。焦距由曲率恢复，不用移动像面冒充；光阑半径跟随新的入瞳计算。手工优化必须选择对应变量，锁定和边界始终有效。最小厚度增加微小内部余量，最终仍做连续区间验收。数值失败不计作零误差，低采样通过不替代 33×33 全视场复核。已通过完整验收的候选会保留，后续失败不能将其覆盖。

每完成一次尝试，面板更新断点。请使用普通“保存项目”写入磁盘；未保存的内存断点不能在应用崩溃后恢复。暂停会取消当前尝试，已完成尝试不丢失。恢复时重新追迹保留候选，修改任务会清空旧断点；引擎搜索格式不匹配时拒绝恢复。搜索是确定性的，没有隐藏随机状态；断点不是 LM 迭代内部的精确快照。

推荐练习：Tessar、50 mm F8、6×4 mm、150 mm 总长、25 µm RMS；开启扩展结构和镜片级玻璃，设置 12 个尝试。完成一两个尝试后暂停、保存、重开并继续。比较候选的全部验收项，而非只看平均 RMS。较大画幅或更快光圈可能仍无解，失败报告不能解释为物理上不存在可行镜头。

镀膜与直透光谱

入口：设计 → 镀膜与透射。镀膜层与表面一起保存在原生 JSON 项目和设计版本中，顺序从物方到像方。CSV 不携带膜层；需要保留镀膜时使用原生格式。

选择表面，加入膜层，设置名称、常数折射率和物理厚度（nm）。最多 32 层，折射率 1–10，厚度 0–10000 nm。可以添加、删除，或清除此面的所有膜层。550 nm 四分之一波长按钮给出 n=1.38、约 99.64 nm 的教学初值，不是厂商工艺配方。

查看结果

点击计算实际光线透射率。使用项目全部视场和全部波长，对中心及 ±0.8 瞳半径的三条子午光线进行真实追迹，取得每一面的实际入射角，分别累计 S/P 直透能量，最后取非偏振等权平均。对照列使用完全相同光路上的未镀膜 Fresnel 透射率。

数值只表示这些采样路径，不能标成整幅相对照度或全瞳平均透过率。被遮挡、瞄准失败、全反射或模型不支持的光线会明确显示失败，不以零值混入平均。报告可以导出逐面入射角和 S/P 反射、透射系数；新增波长即可观察光谱变化。

模型与限制

采用无吸收、均匀、各向同性介质层的特征矩阵。膜层折射率不含色散，基底玻璃则使用项目材料的波长相关折射率。模型检验每面的 R+T=1；含倏逝场、吸收或全反射的情况返回诊断。

目前不模拟多次反射路径、鬼影、散射、表面粗糙度和整镜头偏振状态。直透分析与几何 PSF/MTF 分离：设置镀膜不会改变既有点列、MTF 和测试图结果，也不会简单通过提高对比度来伪造镀膜成像效果。镀膜相位和瞳振幅进入 PSF 需要额外的矢量/波动验证。

理论依据：特征矩阵的场连续性与光学导纳形式，参考 [Oregon 光学讲义](https://atomoptics.uoregon.edu/~tbrown/files/relevant_papers/optics-notes.pdf)。解析测试包含裸界面 Fresnel、Brewster 角、理想单层零反射和多角度能量守恒。

视场、传感器和覆盖检查

入口：「设计 → 设计目标 → 视场与传感器」。右侧「摄影与分析」也可修改同一份传感器宽高。

三种视场定义

- 按物方角度：直接指定半视场列表，界面用度，内部用 rad。适合明确物方方向的对比。

- 跟随传感器：生成中心、短边中点、长边中点、画面角落四个检查位置。

- 按目标像高：输入毫米列表，例如 0, 12, 18, 21.63330765，点击「应用目标像高」。最多 15 个视场。

新建默认启用传感器联动。旧项目保留原来的角度配置，必须显式切换；输入 36×24 mm 本身不会把旧的三角度分析变成全画幅分析。

实际像高反求

理想估计为 θ=atan(h/EFL)。35 mm、36×24 mm 的理想短边/长边/角落半视场约为 18.92° / 27.22° / 31.72°。存在畸变时这些不是实际测试角度。

OOS 沿当前设计的主光线分支反求在当前平面像面上到达目标像高的物方角度。修改材料、间隔、物距或像面后会重新求解。反求失败会报错，不能以理想角度替代。参考波长取配置中最接近 d 线者。

如何解释覆盖报告

- 未验证：没有与目标检查位置匹配的实际测试点。

- 求解未完成：主光线或部分瞳光线无法可靠求解。

- 存在物理遮挡：实际追迹被光学口径裁剪。

- 声明采样通过：这个检查点的配置波长和几何采样没有失败。

匹配像高容差为 0.002 mm。测试更远的像高不自动证明中间位置通过。声明采样通过不表示像差良好、整个像圈连续通过或 MTF 收敛；MTF 状态单独记录。通过比例不是精确相对照度。

范围和常见误区

几何输入边界 ±0.7 rad，约 ±40.107°，不保证任意设计都可在该范围求解。快速衍射模型仍只有 ±8.59°；大视场须单独选择直接 Kirchhoff，并通过其适用性和收敛检查。

按像高比较两个镜头时，实际物方角度可能不同，这是相同画面位置的比较。按角度比较时，实际像高可能不同。报告同时保留这些条件。参见版本对比。

点列图、像差与追迹诊断

点列图与 RMS

「画质 → 点列图」展示各视场、各波长在平面像面上的交点。图内所有波长围绕共同质心显示，保留横向色差；对比时使用共同物理尺度，不按每幅图单独放大。

单色 RMS 为该波长交点相对自身质心的均方根半径；多色 RMS 使用波长权重和共同质心，包含横向色差。它是几何指标，不包括衍射。

失败样本不作为零误差。出现部分失败时，即使剩余光线的 RMS 很小，也不能据此确认镜头良好。缺少完整波段时不显示完整多色指标。

像差与通光

入口「画质 → 像差与通光」。可查看多色 RMS、横向色差、弧矢/子午焦移、近轴纵向色差、每波长质心和畸变。

- 横向色差：配置波长质心 Y 的跨度。

- 场曲/像散：参考 d 线附近微分光束相对当前像面的弧矢/子午焦移，两者差异体现像散。

- 纵向色差：不同波长无限远近轴后焦距相对 d 线的偏移。

- 畸变：无限远以 f·tan(θ) 为参考；有限物距暂不报告该基准。

区分物理失败与求解失败

诊断按视场、波长、阶段、表面和原因统计。物理失败可能是口径遮挡、全反射或未命中；数值失败可能是瞄准未解、曲面迭代不收敛或材料波段无效。

瞄准阶段的试算不是实际物理光路，不会画到剖面上。成功瞄准后重新执行真实追迹；失败路径只画到实际终止位置。点击失败项或瞳面点可定位。缺少路径表示未得到可绘制的物理解，不能补一条直线代替。

近轴指标

有效焦距、后焦距、入瞳与出瞳来自一阶矩阵。F 数用有效焦距和入瞳直径计算，不能直接以实体光阑直径代替。无光焦度或瞳在无穷远时可能未定义；无限远负后焦距表示后方近轴实像条件不成立，应先修改处方。

全视场画质验收报告（1.4）

进入「画质 → 画质验收报告」，先生成几何报告，再按需要勾选逐视场 MTF。几何使用同一处方与当前固定像面，比较 17×17 和 33×33 瞳采样的多色 RMS；变化不超过 max(0.01 µm, 1% RMS) 且没有失败样本时才标记收敛。这个采样门槛不是任意镜头的精度保证。

报告按实际像高列出中心至边缘的 MTF，在 10、30、50 lp/mm 处线性插值弧矢和子午曲线；超过离散频率范围不外推。快速模型超限可切换离轴平面像面模型，但模型失败或未收敛仍显示未验证。几何收敛不代表衍射收敛，衍射收敛也不代表达到了某个产品 MTF 规格。

导出的 JSON 包含完整处方、波长、像面条件、几何采样、覆盖证据、衍射质量数据及失败原因。与其他方案比较时先使用现有「版本对比」统一传感器、视场、光谱和对焦条件；不同像面或视场下的平均 RMS 不可直接作为改进证据。已有像面对焦扫描用于观察共用像面的取舍，不将每个视场各自的最佳焦点拼成一幅平面图像。

可交互瞳面图与光路定位

入口：「画质 → 瞳面图」。本图显示实体光阑平面上的规则圆盘采样，不是出瞳波前或相对照度图。

操作

选择视场、波长和采样数，执行计算。界面提供 9、13、17、25、33 等奇数网格；更密采样有助于发现边缘遮挡，但不是任意瞳拓扑的完整证明。

- 绿色：成功到达像面。

- 红色：物理追迹终止，查看终止面和原因。

- 黄色：瞄准未解，查看目标光阑坐标、残差和试算诊断。

点击样本或用方向键选择，中间剖面高亮对应实际光路，并联动表面。剖面是 Y/Z 投影；离子午面的 X 坐标在瞳面图及数据中查看。

排查方法

整片红色通常需要检查某面有效口径、材料或几何；边缘红色可能是实际遮挡；黄色需要检查瞄准收敛，不能直接视作镜片挡光。缩光阑可能改变问题，但不要以缩小后通过来证明原始大光圈也可用。

不同波长和视场应分别检查。这个图的成功比例按采样点计数，不包含能量权重、Fresnel 损失、镀膜或传感器响应；不能作为精确照度。

自动对焦与对焦扫描

自动对焦

右侧「摄影与分析 → 自动对焦」只搜索像面位置，不改变镜片曲率、材料或光阑。算法在当前像距与正近轴后焦距给出的有界区间内搜索，不保证找到任意系统的全部焦点。

输出候选和几何、规格、通光复核；点击「采纳候选」后才改变当前像距。若无法采纳，查看失败原因列表，而不是只看部分通过的约束。

对焦扫描

入口「调校 → 对焦扫描」。设置像距最小值、最大值、扫描步数、瞳采样以及中心/全视场 RMS 准则，执行扫描。这里的像距是最后一个表面到平面传感器的距离，不是有效焦距。

中心准则需要存在 0 rad 视场。全视场准则综合所有配置视场；候选仍要求所有配置视场和波长满足通光与约束。不能用一个成功中心视场掩盖边缘失败。

曲线逐视场展示光斑变化；推荐点是离散网格最佳点，不是无界连续最优。推荐点位于扫描边界时应扩大区间再算。点击曲线或选择扫描位置后，复核生成候选，再决定采纳。

可靠使用

先保存基准版本；排除相交、负后焦距和瞄准问题；先用较粗扫描确定焦区，再缩小范围。对焦扫描设置随项目保存，临时曲线可能需要重算。

修改当前光学设计后，旧候选失效。取消不改写处方。像高视场随像面移动会重新求角度，因此报告保留每点实际视场。比较固定物方方向时应使用角度视场。

光圈扫描与最佳档位

入口：「调校 → 光圈扫描」。扫描不直接改变当前处方，先产生记录，再复核候选。

设置扫描

输入 F 数列表，最多 12 档，范围 0.5-128；选择几何采样。「每档重新对焦」取消时使用源处方的同一像面；选中后每档独立进行全视场 RMS 自动对焦，不沿用前一档结果。

指定 F 数由近轴入瞳映射为实体光阑半径。光阑机械边界必要时同步扩大，其他镜片不会自动扩大。因此显示实际 F 数仍不保证大光圈能通光。

需要衍射时勾选「逐视场多色 MTF」，再选择「扫描衍射模型」。全档使用相同模型；大视场需要直接 Kirchhoff。它会明显增加计算时间，失败视场记录原因，不会自动换另一种模型。

阅读结果

每档包含实际 F 数、最终像距、逐视场 RMS、失败/总样本数、瞄准失败和物理遮挡。可选 MTF 记录弧矢/子午 10、30 lp/mm 及收敛信息；频率不在有效网格中时显示未定义。

推荐档仅按全部采样无失败时的几何 RMS 选择，不是综合衍射后的最佳光圈。缩光圈可能降低几何光斑，却因衍射降低高频 MTF。

保存和采纳

完整源处方、设置和摘要随项目保存。光学处方改变后旧记录仍可查看和导出，但会标记过期，不能直接采用。旧版无覆盖记录的扫描需重算才能判断传感器覆盖。

选择一档，点击「复核并生成所选光圈候选」；软件重新执行 33×33 追迹和约束检查，通过后才可采纳。固定像面与每档重新对焦的扫描不是相同条件，报告和对比中要保持明确。

带约束优化、画质底线与候选采纳

入口：「调校 → 约束优化」。1.0 将原右侧专业优化设置移到中央工作台，所有变量、锁定、边界、规格约束和报告仍保留。「设计目标」也可按当前设置生成候选。

推荐流程

1. 保存当前项目并记录基准版本；先修正几何、瞄准和材料问题。

2. 设置目标焦距和容差、最大总长、最小中心/实体厚度和空气间隔。按需启用目标 F 数、最小后焦距及最大前组有效直径。

3. 打开多表面变量编辑，添加曲率、间隔、A4-A10，或光阑面半径；设置合理上下限，锁定不想改变的参数。最多 32 个活动变量，材料暂不自动更换。1.3 并行估计双侧导数，以变量边界确定尺度；无效试步先缩短，再增加阻尼，最终仍需通过全部约束。初始光路完全失败时需先修复模型。

4. 设置中心、均衡或边缘优先的目标权重，迭代上限和逐视场画质保护。

5. 生成优化候选，查看真实迭代轨迹、停止原因、逐视场取舍和最终检查。

6. 只有全部条件通过才可采纳；否则可保存候选为待改进版本，继续修改约束或处方。

保护每个视场

在「画质底线与分阶段视场」启用逐视场保护。将「每个视场相对原设计最多退化」设为 0%，可防止为了降低平均光斑而使某个配置视场变差。

也可限制各视场 RMS、最差视场 RMS、最大绝对畸变、横向色差和最低几何采样通过比例。绝对阈值应从基准设计和实际需求制定，界面默认数值不是通用合格标准。通过比例使用 0-1，例如 0.95 表示 95%。

改变视场数量时逐视场绝对底线会清空并提示；全局规则保留。即使数量没变，改了像高含义后也应重新确认底线。有限物距尚无当前无限远畸变参考，启用该项会无法通过。

分阶段扩大视场

启用 50% → 75% → 100% 扩大视场，可从小场逐步求解。每阶段都对照同条件下的原设计，阶段失败就停止，不会冒充全视场完成。

选择「每个设计共用像面，不自动重新对焦」或「每阶段原设计与候选分别重新对焦」，决定是否允许重新寻找各自焦点。重新对焦后的最终处方再次执行全部边界和约束检查。

无法采纳时

先读候选顶部的原因汇总，检查表默认过滤未通过项。显示值可能舍入为 0，但连续几何、细采样通光、变量边界或引擎批准状态仍可能未通过。其他行通过不能抵消失败项。

只有显式允许小于 100% 的通光比例时，物理遮挡才能在保护条件内参与优化；瞄准未解、全反射、求交或材料失败始终不当作零误差。局部阻尼最小二乘不保证全局最优，也不保证每次候选都可采用。

多镜片编组与整体移动

入口：「设计 → 镜组管理」。整枚镜片/胶合组由材料连续段识别；这里的命名镜组可以包含多枚相邻镜片及其间隔。

创建与选择

选择至少两枚相邻完整镜片，填写名称并创建组。范围内的光阑和空气间隔一起归组，不拆开胶合面。最多 20 个连续、不重叠的组。

点击已有组可定位其表面。组名和范围随项目保存；命名版本也保存当时的组定义。

检查移动候选

输入移动量，正值沿 +Z、负值沿 -Z。只改变组前和组后的空气间隔，组内曲率、材料、中心厚度和内部间隔保持不变；组外镜片和传感器位置保持固定。

先检查候选，连续分离或边界空气间隔不合格时拒绝。几何通过后应用并重新分析画质，支持撤销。几何移动可行不等于通光和成像质量仍可行。

第一面是固定坐标原点，包含第一面的组可保存和定位，但不能整体平移。要改变这种结构，需重新规划处方或独立编辑间隔。

新增、复制或删除表面时会清空旧镜组，避免面号错位。恢复版本时恢复该版本的编组，旧扫描会按其源处方判断是否过期。

三维顺序追迹与光线调试器

在 设计 → 三维追迹与调试 打开 OOS-Wollaston v1 的三维顺序追迹工具。

1. 打开单透镜或自己的项目，点击“追迹并检查”。默认五条轴向光线从 z=-100 mm 发射；它们是显式测试光线，并非自动填满入瞳的画质采样。

2. 选择一个表面，设置 X/Y/Z 位移和转角。位移单位 mm，界面转角单位度，计算请求使用弧度。旋转按 Rx、Ry、Rz 顺序，绕表面自身顶点，位置相对原始处方名义顶点。

3. 已在“镜组管理”创建的镜组也会出现在对象菜单。镜组整体绕组首名义顶点旋转并平移，单面位姿先于镜组变换；重叠镜组拒绝计算。展开“发射光线与资源”，编辑起点和方向。方向会归一化。斜光线可同时具有非零 X、Y 分量。零方向会报错。

4. 拖动三维视角滑杆，选择光线，查看每个实际交点、法线、介质折射率、入射/折射角和光程。红色代表失败光线，显示截至最后实际交点；求交失败不会虚构后续路径。

5. 导出可复现请求可交给独立框架 CLI 或 Python 接口执行；导出逐面记录用于诊断。

三维配置随项目保存，支持撤销重做。修改表面名称或顺序后需要重置三维配置，避免位姿套错表面。取消计算或编辑参数后旧结果不会覆盖当前结果。

能力边界：三维配置是一份独立实验配置，现有同轴处方保持不变。点列图、优化器、MTF、像差、技术图纸和历史版本比较仍针对原始同轴处方，不能用它们评价这里的偏心倾斜效果。三维工具目前输出显式光线的几何交点与光程，不提供偏心系统瞳瞄准和衍射分析。只按表面顺序追迹，不搜索非顺序反射或鬼影路径。

框架接口还支持圆、椭圆、矩形和环形附加口径，它们与原始有效口径相交。矩形和椭圆尺寸是半宽/半高。传感器可单独移动、倾斜。偏移表面之间的实体碰撞没有自动认证，机械可制造性需另行检查。

框架源代码位于发行源目录 OOS-Wollaston/；它有自己的 README、API 手册和测试，复制到其他位置也能构建。独立框架版本为 1.0.0，桌面软件版本为 2.0.0。

配置与镜组运动：对焦和变焦

v1.1.0 增加固定传感器的镜组运动。入口为“调校 → 配置与镜组运动”。原有“像面对焦扫描”继续用于寻找像面位置，两者的物理条件不同。

五分钟入门：24–70 mm 示例

1. 从示例列表打开“24–70 mm · 双镜组教学变焦”。打开时画布是 70 mm 参考处方。

2. 进入“配置与镜组运动”，选择“24 mm”，点击“检查当前配置”。编辑配置不会直接更改主画布。

3. 查看实际焦距、F 数、RMS、通光报告和候选光路，再点击“采纳到当前配置与画布”。支持撤销。

4. 复制一个配置，给后组增加 1 mm 位移；选择后组为补偿组，点击“求解对焦 / 变焦补偿”。检查实际焦距可能发生的小幅变化。

5. 点击“固定像面对比全部配置”，展开每一项查看同尺度点列图和覆盖。

6. 展开“手动变焦轨迹与中间位置”。滑杆在当前与下一配置之间插值，点击检查或验证 11 个位置。中间点不是按焦距线性分布，也不自动保证齐焦。

7. 保存原生项目，关闭重开；共享处方、全部配置、行程和光圈规则会恢复。分析结果需重新计算，避免把旧结果当作新配置结果。

该示例是项目自主构建的两正双胶合镜组教学系统，材料为项目已有的合成教学材料，按 Apache-2.0 分发。24/35/50/70 mm 是 d 线近轴有效焦距；传感器为 4×3 mm，按传感器自动检查像高 0、1.5、2、2.5 mm，采用 F/d/C 三波长等权。参考光阑半径 1.2 mm，F 数随焦距约从 10 变化至 29.17。它不是商业 24–70 mm f/2.8 镜头复刻，不表示全画幅、恒定 F 数或经过像差校正的摄影镜头性能。

为自己的镜头建立配置

先在“设计 → 镜组管理”选择一枚或多枚相邻完整镜片创建镜组，再点击“建立多配置模型”。不允许重叠镜组或拆开胶合面；支持首组和整枚镜头的伸缩对焦。

每个配置记录名称、参考物距、各组位移、目标焦距及光圈规则。所有配置共享曲率、材料、内部厚度、传感器、视场与波长。最多 20 个运动组和 30 个配置。

位移单位毫米，正值向像方。锁定表示固定在参考处方的 0 位移。改变行程或锁定不会悄悄修正配置数值；已保存的越界位置会在计算时被拒绝。若重新定义镜组，可用“以当前处方重建配置”建立新参考，原配置可通过撤销恢复。

普通处方参数修改会将改变量同步到共享参考，配置位置不变，旧分析失效。新增或删除表面会清除运动配置，避免面号错位；修改材料导致镜组边界不再完整时也会清除。建议修改结构前先保存命名版本。命名版本包含当时的运动模型，恢复旧版本时不会继续沿用不匹配的新配置。

固定传感器与参考物距

共享参考首面坐标为 0，传感器参考位置为参考处方各厚度之和。每个镜组按指定量平移，组内距离不变，组外未移动的面和传感器保持物理坐标。为复用现有引擎，计算时把新的首面重新归零，同时转换传感器相对位置和有限物距。

有限物距从参考首面计量。首组移动后，计算处方中的物距也随之改变；按物方角度指定的有限物距视场会转换角度，保持原物点位置。按目标像高设置时仍由现有光线瞄准求出实际视场。

对焦与补偿求解

选择一个未锁定且行程非零的组。求解器先扫描整个行程的 25 个位置，再围绕最好位置做三轮各 9 点局部细化。固定其他镜组、物体与传感器；评价目标可选多视场等权 RMS 或中心优先。

所有声明视场仍需通过采样。遮挡、未命中、瞳瞄准失败和几何无效位置不会被计成零误差。只有 RMS 低于用户设置上限、采样没有失败且最好位置不在行程端点，才显示“通过声明验收”。这是一维有界局部搜索，不是全局最优或制造质量保证。

若无法采纳，请检查诊断：镜组越界、锁定、几何相交、空气间隙不足、入瞳未定义、光阑不足或采样失败。边界最优提示扩大行程再验证；未达到 RMS 上限时，不能只放宽上限便声称镜头已经正确合焦。

光圈、比较与呼吸效应

“保持参考实体光阑”固定参考光阑尺寸；“调整到目标 F 数”用实际近轴入瞳换算口径，只允许在参考口径内收缩，不能突破镜片有效口径。移动光阑所在镜组时，光阑随组一起运动。

配置对比始终固定传感器，不分别移动像面；各配置按自身物距计算，采用共享波长、视场定义与采样。点列图使用共同尺度。有限物距倍率由离轴主光线像高与物高估计，不是近轴横向倍率的严格测量；比较相同参考物距的配置可观察呼吸效应，物距不同的倍率不能直接解释为呼吸量。

几何采样通过不代表衍射分析通过，也不代表传感器已经全覆盖。采纳配置后到 PSF/MTF 页面计算并检查模型范围与收敛。通光比例不是精确相对照度。

报告、图纸与技术接口

配置报告包含参考处方、行程、位置、物距、光圈规则、采样、失败诊断及实际分析结果。比较报告记录固定像面条件。技术图纸增加当前配置标识与运动参数表，并在内嵌原生项目中保存全部配置；图纸上的光学指标只属于当前处方，不是全部配置的批量验收。

CLI 的 --request 接口新增 operation: motion，project 为共享参考处方，motion_options 包括 groups、positions_mm、object_distance、min_air_mm、target_f_number、solve_group、sampling、criterion、max_rms_um。solve_group 为 null 时只验证指定位置，为镜组数组下标时执行对焦/补偿求解。返回坐标转换量、固定传感器参考坐标、实际处方、分析结果和扫描诊断。

自动设计多组凸轮曲线、连续全焦段保证、恒定 F 数全程保证、浮动多组联合对焦，以及全焦段全物距联合优化不在本版范围内。

变焦与对焦工作台

v1.2.0 在“调校 → 变焦与对焦工作台”集中提供补偿轨迹、全焦段扫描、多配置联合优化和对焦距离扫描。页面下半部分保留全部镜组与命名配置编辑功能。镜组定义和坐标约定见 配置与镜组运动。

五分钟体验：24–70 mm

1. 打开“24–70 mm · 双镜组教学变焦”。该例仍是 4×3 mm 小传感器、约 f/10–f/29.17 的教学系统，不是商业全画幅恒定光圈镜头。

| 全焦段扫描 | 按命名配置顺序，对每段镜组位置线性插值；不重新对焦 | 每个位置的实际指标、失败诊断和覆盖 |

| 生成变焦补偿轨迹 | 变倍组按配置位置移动，补偿组独立搜索行程；其他组固定 | 离散补偿位置与高采样验收 |

| 多配置联合优化 | 同时评价全部命名配置和视场，传感器固定 | 共享处方与配置候选、优化前后逐视场指标 |

| 对焦距离扫描 | 使用下方活动编辑配置，固定其他镜组，在多个物距求解一个对焦组 | 物距—镜组位移、RMS 和物方半视场 |

全焦段扫描和补偿轨迹要求各配置有相同参考物距与光圈规则。自动补偿的变倍组与补偿组必须不同、未锁定且有行程；其他组位置不能随配置变化。初步求解采样、RMS 上限和最小空气间隙沿用页面下半部分的镜组设置，复核采样不得低于初步采样。每个视场都必须满足 RMS 上限。

“焦距容差”填 0 表示仅报告偏差，正值表示将相对目标焦距的百分比偏差列为验收条件。中间目标焦距是端点目标的线性插值，不代表镜组位置与实际焦距具有线性关系。补偿求解以 RMS 为目标，不保证同时达到任意指定焦距。

“要求传感器全部检查点验证通光”会要求既有覆盖报告中的全部检查点达到 sampled_clear；未测试的角落不能算通过。不开启时仍显示覆盖缺口，不能把扫描通过解释为全画幅已验证。

曲线与加密扫描

曲线横轴按扫描位置顺序排列，节点才是实际计算结果；虚线仅连接节点，不是已验证的连续轨迹。失败点保留在表格中，缺失指标用“—”表示，不当作零误差。可筛选“仅显示未通过位置”。

启用加密后，若相邻点失败或 RMS 差大于阈值，程序在该区段补算中点；最多三轮，总点数受上限约束。它只能增加抽样密度，不能排除采样点之间的碰撞、失焦或急剧变化。初始点数超过上限时会拒绝任务，而不是截掉焦段。每段 2–21 点，总上限不超过 101 点。

空气间隙曲线显示采样估计；验收另用现有几何区间判定。几何通光比例针对声明采样，不是精确照度。畸变显示各波长的最大绝对值；未定义的有限物距畸变不强行生成数值。

多配置联合优化

支持最多 32 个变量：共享曲率、共享厚度 / 空气间隔，以及指定配置的镜组位置。添加位置变量前，在页面下半部分选中对应的活动编辑配置。重复变量、越界边界和锁定镜组会明确报错。

共享厚度改变时，最后空气间隔作反向补偿，保持参考传感器坐标；最后像距不能单独作为变量。镜组位置还必须满足行程和机械间隙。材料保持不变。

求解采用有界坐标搜索，最多 30 轮，以全部配置、全部视场等权 RMS 为目标。每个候选必须满足逐视场 RMS 上限、玻璃最薄实体、空气间隙，以及启用的焦距与覆盖条件。默认允许退化为 0%，任何视场都不能比原设计更差；可以显式增加允许比例。严格保护可能使搜索找不到可采纳的改善，这不是程序故障。

搜索结束后，原设计和候选都用相同的复核采样重新计算。只有全部配置通过约束、逐视场退化不超限且总体 RMS 确有改善，才能采纳全部共享处方与配置。没有改善时保留诊断，不把原设计重新包装成优化成功。点击配置可查看优化前后共同尺度点列图。

这是局部、可行候选搜索，不承诺全局最优；建议从已能通光的配置和少量合理变量开始。几何无效或失败光线不会作为零误差参与优化。当前没有非球面系数、多组联合对焦、自动材料替换或衍射目标联合优化。

400 mm 对焦距离扫描

使用 400 mm 修正版时，在镜组管理中把全部完整镜片建立为一个组，再建立多配置模型。可先以行程 −25 至 +5 mm、最小空气间隙 0 mm、RMS 上限 50 μm、初步采样 7×7 作为该教学模型的验证设置。

工作台选择“对焦距离扫描”，指定整枚镜头为对焦组，近端 10,000 mm、远端 100,000 mm、有限物距位置数 3，并包含无限远。有限物距按对数间隔采样，约为 100 m、31.62 m、10 m；物距从参考首面计量，传感器不动。以上是此示例的验收设置，不能照搬为其他镜头的物理行程。

程序显示每个位置的实际物方半视场。在同一目标像高定义下，可以比较视角变化；固定物方角度设置的角度变化还包含坐标转换，不能直接当作呼吸效应。不同物距的倍率变化也不能直接称为呼吸百分比。

保存、取消与报告

工作台设置自动进入项目；计算记录需要点击“将完整记录保存到项目”，随后保存项目文件。一个工作台保留一份完整记录，命名版本可保留其他研究状态。最多 30 个命名配置，超过此数的扫描仍可作为完整记录保存和导出。

项目重开会恢复设置、逐点位置、指标与诊断，不直接信任历史验收来覆盖处方。改变共享处方、镜组、配置或研究条件后，旧记录显示过期；重新计算后才可采纳。取消或修改输入会中止任务，旧任务不能覆盖新设计。JSON 报告包含输入和计算条件，CSV 提供可编辑的位置与指标表；它们不等于制造用凸轮图纸。

CLI 新增 operation: motion_study，study_options 包含 mode、motion、configurations、扫描设置、verification_sampling、约束和 variables。返回 reference、configurations、before、points、accepted 和固定传感器坐标。每个 points 项都保留 accepted、diagnostic、逐视场 RMS、通光及覆盖信息。原有 motion 接口与项目结构继续支持。

PSF / MTF 不在本工作台批量计算。采纳配置后请到画质页面单独分析，并检查适用范围和采样收敛；本版未扩大衍射模型的验证范围。

持久化版本与同条件对比

入口：「交付 → 版本对比」。顶部「记录版本」可立即保存当前处方快照，命名和备注可在版本面板管理。

记录与恢复

保存当前为版本不会另存磁盘文件，需要再「保存项目」才能跨会话保留。最多 20 个版本，每个包含独立处方与当时镜组，不嵌套版本历史。删除版本不改变当前镜头；恢复版本会替换当前处方，可撤销。

设计目标、优化设置与扫描记录属于项目工作区；恢复不同光学处方后，旧扫描可能过期。候选也可以保存为版本，待进一步研究。

统一比较配置

选择 A、B，当前设计也可作为其中之一。视场定义、波长及权重、物距和传感器不一致时，需要明确勾选「仅在此次计算中将 B 统一为 A 的配置」。该对齐只用于计算，不偷偷改写保存版本。

按像高比较代表相同画面位置，不同设计可能需要不同物方角度；按角度比较则代表同一物方方向。报告保留实际角度与像高。

对焦条件

- 共用 A 的绝对平面像面：A/B 使用同一个 Z 坐标，适合固定传感器位置比较。若该平面位于 B 末面之前，明确报错。

- A / B 分别自动对焦：各自寻找局部最佳平面，每个设计的所有视场仍共用一个平面。适合比较重新对焦后的潜力，不应与固定像面结果混为一谈。

点击「计算同尺度对比」重新执行 33×33 几何分析。点列图共享尺度。之后可计算所选视场的多色 PSF / MTF 对比；两边使用同一个显式衍射模型。

PSF 比较转换为共同物理窗口和强度密度，MTF 使用同一 lp/mm 频率轴，不通过分别拉伸图像隐藏差别。导出报告记录实际计算处方、像面、配置、方法、采样、覆盖与收敛结果。

PSF、MTF 与采样收敛

1.3 性能：原生应用在同一进程内复用已收敛结果，精确比较处方、材料、波长、像面、模型与采样设置。最多缓存 8 项且 PSF 样本不超过 64 MiB，超出后淘汰最旧项。重复 MTF 和测试图可受益，修改输入自动失效。直接离轴积分不再限制为最多 8 个线程。没有降低收敛标准，也没有统一的冷计算提速保证；开发服务器每次启动 CLI，不共享原生进程缓存。

入口：「画质 → PSF / MTF」。先检查几何和通光，再选择模型、视场、单色/多色和采样上限，点击「计算 PSF / MTF」。

选择方法

快速模型适用于小视场 ±0.15 rad，约 ±8.59°，还要求参考球方向正弦不超过 0.25 等检查。不能因为几何能到 40°，就假设快速 MTF 也支持。

「离轴 · 平面像面 Kirchhoff」使用实际参考球、瞳映射、遮挡和光线管振幅，在最终平面传感器直接积分传播距离。可研究更大离轴视场，但仍要求稳定可逆瞳映射、空气像方、正参考距离、横向方向正弦不超过 0.85 和像面 Nyquist 合格。

35 mm 全画幅示例的角落应使用直接法。400 mm 工作区的约 3.1°角落可能满足快速范围，但比较时仍应显式使用同一模型。

收敛与适用性

采样上限 128 适合初步检查，256 用于更细验证。软件比较相邻瞳采样，检查 MTF 最大变化 ≤0.015、PSF L1 ≤0.04、相邻相位步 ≤0.25 波长、外侧 10% 窗口能量 ≤0.005；直接法还要求 Nyquist 比例小于 1。

只有通过门槛才返回可用结果。不通过应查看原因：可能散焦、像差太大、窗口不够、瞳映射复杂或采样不足，不应把失败改成零像差。可取消耗时任务；修改输入会使旧结果失效。

读图

PSF 是单位计算窗口能量的点扩散函数。对数显示只改变显示亮度，不改变光学计算。视窗可查看中心 128、256 或完整区域；下方标尺使用 µm。

MTF 横轴为空间频率 lp/mm，纵轴为调制度传递。S 为弧矢 X 方向，T 为子午 Y 方向。切换频率上限只改变显示，不重新优化镜头。高频对采样更敏感；不要用不同尺度或不同波长权重比较。

多色与限制

多色按项目权重非相干叠加；每波长计算窗口内归一化，不代表总光通量或真实传感器响应。模型是标量近似，不包含 Fresnel 界面损失、偏振或镀膜。

边缘能量是有限窗口指标，不是缺失能量的严格误差界。图像看起来清晰不代表任意孔径/视场都经过验证。点击「导出 MTF 报告」保留处方、方法和收敛信息。

测试图近似成像

入口：「画质 → 测试图成像」。选择网格、分辨率条纹或点光源阵列，指定「成像衍射模型」，点击「计算多色测试图」。

结果代表什么

每个视场用对应多色 PSF 对局部平面测试目标卷积，采用周期延拓和局部平移不变假设。结果用于理解光斑、衍射和方向分辨率如何改变局部细节。

不是把整张照片通过完整镜头渲染，也不从普通照片推断真实物距、景深或散景。当前不提供完整整幅空间变化卷积与畸变重映射。不同视场小图的物理范围可能不同，应阅读每幅标尺，不只比较屏幕像素大小。

方法和失败

小视场可用快速法；大视场选「直接 Kirchhoff · 离轴平面像面」。每个配置视场分别进行衍射适用性和收敛检查，成功与失败分别展示。

某个视场没有图像时，查看该场诊断，不以其他视场图像替代。几何通过但衍射失败可能来自相位/窗口采样，不等于镜头完全不通光。模型与限制见PSF / MTF。

修改波长、像面或光学处方后需要重新计算。若想判断固定传感器下的改进，应在版本对比统一像面和测试条件。

技术图纸 PDF 导出

入口：「交付 → 技术图纸 PDF」，或顶部「文件与导出 → 导出技术图纸 PDF」。图纸在本机生成，中文字体已随软件提供，无需 Python、打印机或网络。

操作步骤

1. 保存当前项目或记录基准，确认项目名称和处方。

2. 预览总剖面；需要波动结果时勾选「加入逐视场多色 PSF / MTF」，明确选择快速或直接 Kirchhoff。

3. 点击「导出技术图纸 PDF」。软件冻结当前处方，重新计算几何、实际视场和 33×33 几何分析；不会自动重新对焦。

4. 若勾选衍射，以同一种方法对全部视场做多色 256 上限分析。失败场记录原因，其余场可继续。

5. 完成后选择 PDF 保存位置；取消保存不会改变项目。计算阶段可取消。编辑设计或离开图纸页会终止尚未完成的导出。

图纸内容

- 总览：项目说明、时间、有效焦距、后焦距、近轴 F 数、传感器、物距、光阑和源项目哈希。

- 总装剖面：等比例矢量轮廓、首顶点至像面长度、光阑与像面位置。

- 逐镜片/胶合组分图：局部等比例剖面、面号、轴上长度、机械包络最大直径。胶合内部各段厚度和各面直径见处方表。

- 全部表面：顶点 Z、半径与曲率、间隔、有效直径、机械直径、环带形式和面后材料。

- 全部非球面系数：K、A4、A6、A8、A10，包含零值和单位。

- 材料快照：常数折射率或 Sellmeier、有效波段、完整系数与来源。

- 视场、光谱、像面、覆盖状态、点列/色差/畸变摘要、瞳参数、几何分离和诊断。

- 可选逐视场 PSF 图、S/T MTF 曲线、方法和收敛参数。

- 镜组、版本摘要、目标和优化/扫描设置；历史扫描明确属于其源处方。

精确源数据与附件

PDF 内嵌 project.oos.json（完整项目）与 analysis.json（本次结果摘要）。源项目保存未舍入数值、所有版本与历史扫描；总览 SHA-256 对应该附件的 UTF-8 字节。用支持附件的阅读器提取后，可重新在 OOS 打开。摘要省略大型光线、点列和 PSF 数组，不是完整重新积分所需的瞳数据集。

PDF 文本可检索，矢量剖面缩放不失真。中文名称可显示；字体未收录的少数字符会用问号替代，精确源文本仍保留在附件。图形按各页视窗缩放，尺寸以数值为准，不从打印图形量取。

图纸的工程范围

它是一份名义光学技术记录。未指定的加工公差、倒角、胶层、表面质量、镀膜、装配基准和强度不会凭空补全，不可直接作为完整加工验收图纸。几何/追迹有问题时仍可导出草稿，首页及检查页明确标注；未算 MTF 也会明确记录。

报错排查与常见问题

显示无法采纳，但表格看起来都通过

先读候选顶部的「无法采纳」原因汇总。检查表默认显示未通过项，可切换过滤查看全部。引擎批准状态、细采样通光、变量边界、阶段完成与连续几何检查都可能阻止采纳；表格舍入值为 0 不表示实际边界一定满足。其他通过项不会抵消失败项。

设置了全画幅，为什么角落仍未验证

传感器大小与测试视场是不同设置。到「设计 → 设计目标」显式选择传感器联动或角落像高，重新计算。旧项目保留原角度，旧扫描缺少覆盖记录时必须重算。参见视场与覆盖。

视场反求或瞳瞄准失败

检查处方是否先能在轴上成像，检查曲率符号、玻璃/空气顺序、有效口径、光阑位置和几何。逐步增加视场以定位失效区间。瞄准失败不等于已证明物理遮挡；黄色瞳点没有真实光路，不应通过画一条直线来掩盖。

焦距、F 数与目标相差很大

目标不会自动实现设计。曲率输入为 1/mm，基础镜片半径则为 mm；注意两者区别。400 mm f/2.8 需要约 142.86 mm 的近轴入瞳，仅按商品示意图复制形状、用通用材料和小前径不会复现商品性能。

后焦距为负或自动对焦拒绝

无限远负后焦距表示后方近轴实像条件不成立。先调整处方而不是不断增大像距。自动对焦只改变当前最后一段空气距离，不能把任意错误镜头变成实像系统。

MTF 超出模型或数值不收敛

快速模型有独立小视场限制，大视场需选择直接 Kirchhoff。直接法也会拒绝复杂瞳映射、Nyquist 不足或能量窗口不足。先检查焦点、遮挡和色差，再尝试 256 采样。不能以更大数字上限代替验证。

保存后结果不见了

处方、版本、镜组和光圈扫描摘要会保存；临时 PSF、瞳点和部分分析曲线需要重算。结果报告 JSON 与原生项目用途不同。磁盘文件是否保存看项目名旁状态，不看自动恢复提示。

PDF 未生成、取消或只有草稿

计算可取消；保存对话框取消不写文件。几何与波动失败会写进图纸诊断而非冒充通过。PDF 上限 32 MB；项目附件上限仍受原生 4 MB 约束。换成较短项目名称也可排除系统路径问题。

界面区域太小或滚动错位

光学术语与单位速查

- EFL / 有效焦距：由系统光焦度定义，不等于总长或末面到传感器的距离。

- BFL / 后焦距：无限远近轴焦点到末面顶点的有符号距离。

- 像距：最后一面到当前平面传感器的间隔；通过自动对焦可改变。

- 入瞳 / Entrance pupil：从物方观察光阑的近轴像；出瞳是从像方观察的像。

- F 数 / F-number：有效焦距除以入瞳直径。显示值为近轴规格，有限物距不是已校正工作 F 数。

- 光阑 / Aperture stop：限制轴上光束的指定表面；有效口径用于物理裁剪。

- 半视场 / Field angle：光轴到一个物方方向的夹角；全视角通常为两倍对称半视场。

- 像高 / Image height：平面传感器上参考主光线的径向位置，单位 mm。

- 主光线 / Chief ray：瞄准实体光阑中心的光线；边缘光线瞄准光阑边缘。

- 曲率 / Curvature：c=1/R，单位 1/mm；R 为有符号曲率半径，单位 mm。

- K：圆锥常数，无量纲。偶次非球面 A4-A10 乘 r 的对应次幂，单位随幂次变化。

- 矢高 / Sag：曲面相对顶点的轴向位移 z(r)。

- RMS 光斑半径：关于质心的均方根半径，界面单位 µm，越小通常意味着几何像差越小。

- OPD / 光程差：实际波前相对参考球的光程差；波前 RMS 可用 mm 或波长数表示。

- PSF / 点扩散函数：理想点目标经过系统后的像面强度分布。

- OTF / 光学传递函数：PSF 的复频域表示；MTF 为归一化 OTF 的幅值。

- S / Sagittal：弧矢 X 方向；T / Tangential：子午 Y 方向。

- lp/mm：每毫米线对数；不能直接等同于单个像素的像素数。

- 遮光比例：按发射样本计数的物理裁剪，不等于精确相对照度。

- 采样收敛：增加采样后结果变化低于门槛；只说明指定模型与配置的数值稳定性。

- 常用换算：1 mm = 1000 µm；1 µm = 1000 nm；rad = 度 × π/180。

理解术语后可按新手教程实践；开发和公式细节见技术文档。

技术文档：模型、算法、接口与验证

架构与边界

React / TypeScript 提供编辑和图表，Tauri 2 提供 Windows 文件、任务和安装外壳，自研 Rust CPU f64 核心提供顺序追迹、分析与优化。CLI 和桌面共用核心。PDF 在独立浏览器工作线程使用 pdf-lib/fontkit 和内置中文字体生成；源项目与分析条件冻结后传入，不修改光学核心。

2.0 将核心独立为 OOS-Wollaston v1。既有画质和设计模型仍为旋转对称顺序系统，镀膜直透分析保留。新增三维实验支持表面/镜组偏心倾斜、斜光线和倾斜传感器的顺序几何追迹，详见 三维追迹。三维实验不参与同轴优化、PSF/MTF 或 PDF 名义图纸。没有自由曲面、非顺序反射分支、多次鬼影、完整偏振追迹和真实三维场景渲染。

坐标、单位和材料

内部 mm、rad、nm；+Z 从物到像，第一面顶点为零；场角位于 Y/Z 面。表面材料是面后的介质，入射介质固定 n=1。有限物点为 (0,-d tan θ,-d)。曲面矢高：

z(r) = c r²/(1+sqrt(1-(1+K)c²r²)) + A4 r⁴ + A6 r⁶ + A8 r⁸ + A10 r¹⁰。

Sellmeier n²=1+Σ Bi λ²/(λ²-Ci)，λ 为 µm。材料有效波段在追迹前检查。原生 JSON 使用 round-trip 浮点解析，v3 的 field_spec 才是像高视场定义，fields 为初始角度缓存。

近轴、求交和瞄准

近轴状态为 [高度,n×倾角]，通过折射/传播矩阵计算光焦度、BFL 和瞳共轭。精确追迹以矢高方程求交，Newton 迭代带步长和次数限制，使用向量 Snell 折射，累积材料光程。分别报告未命中、口径遮挡、全反射、定义域与数值不收敛。

主光线采用近轴初值、阻尼 Newton 与视场延拓；目标瞳点围绕主光线逐步延拓，检查相对 Jacobian。瞄准试算忽略上游口径，找到解后重新检查真实全部口径。该方法不穷举折叠或断裂瞳的所有分支。

目标像高沿连接轴上主光线的分支求角度，几何输入界限为 ±0.7 rad。公开验证覆盖特定 32°/40° 原创处方，不保证任意镜头可解。

几何指标与优化

圆盘内规则网格采样，单色 RMS 以自身质心，多色以共同质心。失败不是零误差。畸变仅无限远采用 f tan θ 基准；色差和微分场曲定义见相关帮助。

局部优化为有限差分 Jacobian 的阻尼最小二乘，变量投影到用户边界。画质权重、焦距与尺寸约束归一化；最终使用 33×33 通光和连续几何复核。允许分阶段扩大视场与各设计分别对焦，最终实际处方重新计算约束。它不是全局优化。

衍射与局部成像

快速模型在规则参考球瞳网格使用局部传播展开与 FFT，有独立视场/方向限制。直接法在最终平面像面直接求和球面传播距离，含实际瞳映射面积、光线管振幅和倾斜因子。多波长按指定权重非相干叠加，计算窗口内归一化；未包括界面 Fresnel、镀膜或传感器响应。

收敛门槛和有限窗口限制见PSF / MTF。成像为局部周期目标与 PSF 卷积，不是完整空间变化渲染。

JSON 请求接口

CLI：oos-cli --request，从 stdin 读一个 JSON，正常 stdout 输出 JSON，错误 stderr 返回非零。--request-progress 输出 NDJSON 进度，最后一行 result。请求中的 project 是完整光学处方对象，不是路径，工作区由 UI 在调用前分离。

{"operation":"analyze","project":{},"sampling":25}

上例 project 只是结构占位，必须替换为有效项目。常用操作包括 validate、geometry、field_plan、analyze、trace、autofocus、focus_scan、aperture_scan、checks、stop_map、move_group、optimize、wave、preview、pupil、pupils。不同操作的额外选项分别为 focus_options、aperture_options、group_move、constraints、optimization 和 wave_options。

{"operation":"wave","project":{},"wave_options":{"method":"sphere_kirchhoff","field_index":0,"wavelength_nm":null,"max_pupil_samples":256}}

wavelength_nm=null 表示多色；method=fast 或 sphere_kirchhoff。视场索引和表面索引从零开始；界面显示 S1 从一开始。Rust execute(Request,&AtomicBool) 与 execute_with_progress 共用实现。

任务、文件与来源

每个任务带独立 ID 和取消标志；前端用修订号和 AbortController 阻止旧结果覆盖新设计。不同面板可独立运行，切换/编辑导致的失效由各控制器处理。原生项目和 PDF 都通过同目录临时文件原子写入。

源代码采用 Apache-2.0，目录玻璃、字体和依赖分别保留来源及许可证。PDF 包含源项目 SHA-256 和精确附件，显示表格允许舍入，不能替代精确项目。
