# 1.5.0 功能范围与发布验收

## 1.5 新增

- 有界约束恢复、几何可行性优先和完整验收候选保留；手工优化仍限 32 个活动变量，不自动解锁或放宽边界。
- 三种结构变体和镜片级材料替换；有限预算，逐片单独替换，不承诺全局拓扑生成或可制造性。
- 真实尝试级检查点：保存项目后可重开续算，当前未完成尝试重跑；不是 LM 内部状态快照。
- [固定基准](validation-benchmark-1.5.json)：4/12 → 9/12；较多恢复计算带来时间成本，不作为速度提升声明。
- [回归](validation-design-1.5.json)：经典结构、24–70mm、400mm 处方未改变。

## 1.4 新增

- 持久化设计任务；显式应用到当前模型的传感器、视场和优化约束。
- 四种结构可自动比较，三个指定玻璃对逐一重新优化；有限预算，不承诺全局最优。
- 按实际像高验收短边、长边、角落；覆盖约束可用于既有优化。
- 全视场 RMS 17→33 收敛和可选 10/30/50 lp/mm MTF 报告；不能计算的项保留失败原因。
- 统一任务队列，最多两个并行任务、排队取消与暂停启动新任务。1.4 无求解器断点；1.5 新增自动设计尝试级断点，仍无硬件占用百分比控制。

## 还不能声称完成的原方案目标

- 任意瞳拓扑、高 NA/大视场的可靠波动解；照度/斜因子/透射振幅模型与完整可交互波前图。0.2.0 已完成规则参考球面反解、多色叠加、OPD 诊断导出及独立收敛报告，限定范围见 [衍射说明](DIFFRACTION.md)。
- 0.7 瞄准沿主光线稳定分支求解，并检查相对 Jacobian 翻转；仍不保证找到任意折叠或断裂瞳的全部解。瞄准未解不等于已证明的物理遮挡，失败样本不能作为零误差进入优化。
- 完整整幅平面目标的空间变化卷积与畸变映射。当前预览是每个视场的周期延拓局部多色平面目标，显示实际物理宽度，仍采用局部平移不变假设。
- 边缘厚度的精确连续极小值报告、机械强度、公差与装配约束。0.4 支持可配置中心/实体厚度及空气间隔下限，并用连续区间确认通过；表格实际最薄数值仍为采样估计。0.6 UI 与 CLI 均支持多面曲率、间隔、A4–A10、边界与锁定。
- 画布几何拖拽编辑。当前有合并撤销的光阑滑块，支持低采样拖动预览与结束后的精细计算；其他参数通过输入框提交。
- 更完整的材料目录、熔次与温度模型、全局优化与整幅成像；0.6 已加入 8 种可追溯目录玻璃和多表面变量管理。
- 干净 Windows 虚拟机断网安装验证、真实新用户 10 分钟可用性研究、签名分发。构建成功不替代这些验收。
- 非顺序追迹、吸收/色散膜料、镀膜相位 PSF、一般偏振传播、鬼影、真实 3D 散景、公差、GPU 与 Web 发布仍为后续路线；1.3 镀膜只包含限定的子午直透能量分析。变焦已有以下限定实现，不代表制造凸轮或连续齐焦保证。

## 发布前检查

1. 在无开发工具、无 WebView2 的干净 Windows 机器断网运行 NSIS 安装包。
2. 验证原生文件保存/导入、取消、重启恢复与新用户教程。
3. 为数值病态镜头扩充参考数据，固定每项误差容限和采样收敛条件。
4. 第三方资源 / 依赖复核见 [开源准备记录](OPEN_SOURCE_PREPARATION.md)和[许可审查](THIRD_PARTY_AUDIT.md)，包括两处上游文本缺失例外；当前安装包未签名，公开说明中保留该状态，后续签名流程独立管理密钥。

所有“已通过”的数值结论只针对仓库中明确列出的算例。教学材料与处方不能用于推断商品镜头的性能。

## v1.1.0 镜组运动

新增共享处方多配置、固定传感器镜组对焦、手动变焦与单补偿组求解，原有功能保留。支持行程、锁定和连续几何间隙检查。24–70 mm 教学示例限制为 4×3 mm 传感器、小光圈，并非商业全画幅镜头。关键配置和中间点经过追迹；离散检查不等于连续齐焦保证。详见 [教程](manual/motion.md) 与 [验证](validation-motion-1.1.json)。

## v1.2.0 变焦与对焦工作台

新增补偿轨迹生成、全焦段扫描与有限自适应加密、多配置联合优化和物距扫描。支持共享曲率 / 厚度 / 各配置位置变量、逐视场退化保护和高采样复核，固定传感器；失败位置保留并阻止不合格候选采纳。扫描设置、结果与来源条件可保存重开，命名版本保留研究状态。教程见 [工作台](manual/study.md)，独立数值证据见 [1.2 验证](validation-study-1.2.json)。

联合优化为有界坐标搜索，可行域外不作全局寻优；轨迹为有限离散位置，不证明连续齐焦；不新增 PSF/MTF 模型认证。已有 24–70 mm 示例仍限定小传感器、小光圈。完整手册更新为 22 章。
